# Excel 保護解除ツール (excel_unprotect)

自分が所有する Excel ファイルで、**「ブックの保護」や「シートの保護」のパスワードを
忘れてしまった**ときに、その保護（編集ロック）を解除するためのツールです。

パスワードを「解読」するのではなく、**保護そのものを取り除きます**。
これらの保護は暗号化ではなく単なる編集ロックのため、ファイルの中身を
壊すことなく安全に外せます。

---

## ✅ できること

以下の「編集ロック系」の保護を解除します。

| 保護の種類 | 説明 | XML要素 |
|---|---|---|
| ブックの保護 | シートの追加・削除・移動・非表示などの禁止 | `workbookProtection` |
| シートの保護 | セルの編集禁止など | `sheetProtection` |
| グラフシートの保護 | グラフシートの編集禁止 | `sheetProtection` |
| 書き込み予約 | 「読み取り推奨」/書き込みパスワード | `fileSharing` |

**対応形式:** `.xlsx` / `.xlsm` / `.xltx` / `.xltm`
（ZIP ベースの新しい Office 形式 = OOXML）

## ❌ できないこと（重要）

- **「ファイルを開くパスワード」（暗号化ファイル）は解除できません。**
  これは本物の AES 暗号化なので、正しいパスワードが必要です。
  → ツールは暗号化ファイルを自動で検出し、その旨を表示して中断します。
- **古い `.xls` 形式（BIFF）は対象外です。**
  一度正しいパスワードで開いて `.xlsx` として保存し直してからご利用ください。

> ℹ️ 「ブックの保護」と「ファイルを開くパスワード」の違い
> - **ブック/シートの保護**：ファイルは普通に開けて中身も全部見える。誤編集を
>   防ぐための“編集ロック”にすぎず、パスワードのハッシュがファイル内に
>   残っているだけ。→ 本ツールで外せます。
> - **ファイルを開くパスワード**：ファイル全体が暗号化されていて、正しい
>   パスワードなしには中身を一切開けない。→ 本ツールでは外せません。

## 動作環境

- Python 3.8 以上（標準ライブラリのみ。**追加インストール不要**）
- GUI 版を使う場合は `tkinter`（多くの Python に標準同梱）

---

## 使い方

### 🖱 GUI（画面）で使う場合 — かんたん

```bash
python3 excel_unprotect_gui.py
```

1. ［① Excel ファイルを選ぶ…］でファイルを選択
2. 掛かっている保護が一覧表示される
3. ［② 保護を解除する］を押して保存先を指定 → 完了

### ⌨️ コマンドラインで使う場合

```bash
# 基本：foo.xlsx → foo_unprotected.xlsx を作成
python3 excel_unprotect.py foo.xlsx

# 出力ファイル名を指定
python3 excel_unprotect.py foo.xlsx -o なし.xlsx

# 元ファイルを直接書き換え（foo.xlsx.bak のバックアップを自動作成）
python3 excel_unprotect.py foo.xlsx --inplace

# 解除せず、どんな保護が掛かっているかだけ確認
python3 excel_unprotect.py foo.xlsx --dry-run
```

終了コード: `0`=成功 / `2`=ファイルが無い / `3`=非対応（暗号化・.xls・破損）

## 仕組み

`.xlsx` などの新しい Excel ファイルは、実体が ZIP アーカイブで、中に
XML ファイルが入っています。「ブックの保護」「シートの保護」は、それぞれ
`xl/workbook.xml` と `xl/worksheets/*.xml` の中に `workbookProtection` /
`sheetProtection` という**空のタグ**として保存されています。

本ツールは ZIP を開いてこれらのタグだけを取り除き、それ以外の内容
（データ・書式・数式など）は一切変更せずに書き戻します。パスワードの
解読・総当たりは行いません。
