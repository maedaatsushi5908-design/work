# 総括表 自動転記・照合マクロ

`01 総括表` の数量を、`02`〜`08` の各数量計算書から自動で拾って入れる。
入れる前に必ず差分を見せ、書き込む前に総括表のバックアップを取る。

対象: 東白川特２高層配水池揚水管取替工事（ただし他工事にも流用できる設計）

## できること

| マクロ名 | 動き |
|---|---|
| `定義シートを作成` | 転記のルールを書いた「転記定義」シートを作る。**最初に一度だけ** |
| `照合実行` | **書き換えない。** 総括表の値と計算値を突き合わせ、「照合結果」シートに一覧を出す |
| `転記実行` | 差分を見せて確認を取り、OKならバックアップを作ってから書き込む |

総括表の数量40項目のうち、**26項目が自動転記の対象**。残り14項目（仕切弁・空気弁・
フランジ継手など）は図面から数える手入力項目なので、照合結果に「手入力」として
現在値だけ表示する。

## 導入手順

### 1. 総括表を .xlsm で保存し直す

`01 総括表...xlsx` を開き、**ファイル → 名前を付けて保存 → ファイルの種類を
「Excel マクロ有効ブック (*.xlsm)」** にして保存する。
`.xlsx` のままではマクロを保存できない。

### 2. VBE を開く

`Alt` + `F11`

### 3. モジュールを入れる

4つのファイルを取り込む。**コピー＆貼り付けを勧める**（文字化けしないため）。

1. VBE のメニュー → **挿入 → 標準モジュール**
2. GitHub 上で `M_Util.bas` を開き、中身を全部コピー
3. さきほどの標準モジュールに貼り付け
4. `M_Config.bas` `M_Engine.bas` `M_Main.bas` も同様に、**それぞれ別の標準モジュール**に貼り付ける

**先頭の `Attribute VB_Name = "..."` の行は必ず削除すること。**
この行が消えるのはインポートしたときだけで、貼り付けでは残り、
コード画面では無効な行なのでコンパイルエラーになる。
モジュール名はプロパティウィンドウの `(オブジェクト名)` で `M_Util` などに直す。

> インポート機能（ファイル → ファイルのインポート）を使いたい場合は、
> `sjis/` フォルダの方の `.bas` を使うこと。こちらは Shift-JIS で保存してあるので
> 日本語が化けない。

### 4. 転記元ファイルを同じフォルダに置く

`01`（総括表）と `02`〜`08` を**同じフォルダ**に入れておく。
ファイル名は元の日本語名のままでよい。**先頭の番号（`02` `05-1` など）で
探す**ようにしてあるので、`02　東白川　鋳鉄管製造　数量計算書.xls` でも見つかる。

別フォルダにある場合は、実行時にフォルダを尋ねてくる。

### 5. 定義シートを作る

`Alt` + `F8` → `定義シートを作成` → 実行

「転記定義」シートができる。中身を見れば、どこから何を拾っているかが全部分かる。

## 使い方

### まず照合

`Alt` + `F8` → `照合実行`

「照合結果」シートに一覧が出る。

| 判定 | 意味 |
|---|---|
| 一致 | 総括表の値＝計算値。問題なし |
| 差異 | ずれている。**転記ミスか、計算書側が更新された** |
| 手入力 | 自動化対象外。現在値のみ表示 |
| エラー | 元ファイルが無い／シート名やキーが変わった |

### 問題なければ転記

`Alt` + `F8` → `転記実行`

差分の件数を出して確認を求める。OKすると `BK_日付時刻` という
バックアップシートを作ってから書き込む。元に戻したいときはこれを見る。

## 他の工事に流用するには

**コードは触らない。「転記定義」シートを直すだけ。**

| 列 | 意味 |
|---|---|
| 有効 | 空欄か `×` にするとその行を無視する |
| 区分 | `自動転記` か `手入力` |
| 名称／摘要 | 総括表での表記。転記先セルの中身と合っているか自動で点検する |
| 転記先セル | 総括表のセル番地（例 `D10`） |
| 元ファイル／元シート | 転記元。ファイル名は先頭番号が合えばよい |
| キー1列／キー1／キー1方式 | 行を探す1つ目の手がかり。**結合セルで下が空でも上から補完する** |
| キー2列／キー2／キー2方式 | 行を絞る2つ目の手がかり |
| 行オフセット | 見つけた行からの相対行（`合 計` の次行を読む場合は `1`） |
| 値列 | 値がある列（`F` `AO` など） |
| 見出し行／見出しキー | 列を見出しから探す場合に使う（口径ごとに列が変わる表など） |
| 丸め | 小数点以下の桁数。空欄なら丸めない |

照合方式は3種類。

- `部分` … 表記ゆれを吸収して部分一致（既定）
- `完全` … 完全一致。`SP400A` と `φ400` を区別したいときなど
- `口径` … 数字だけ取り出して数値比較。`400A` `φ400用` `φ400 1種管` がすべて 400 として一致する

比較の前に、全角→半角・空白除去・`φ` 除去・大文字化を行うので、
`ＧＸ形 直 管` と `GX形直管` は同じものとして扱われる。

## 注意点

- **`03` 切管表の φ400 は最終シート `GX　400 (4)` の合計を使っている。**
  シートを増やした場合は定義シートの元シート名を直すこと。
- **`05-1` は `延長集計表  採用(伏越削除)` を見ている。**
  よく似た `延長集計表` シートもあるが、そちらは採用前の版。
- 挿口加工費は `02` の「GX形 挿口リング」から取っているが、
  `03` 切管表の W列 とも一致するはず。ずれたらどちらかが古い。
- 総括表の `K173:K178` にある VLOOKUP は参照先 `O173:R204` が空で、
  常に空白を返す。使われていないので消してよい。
- 転記元ブックは読み取り専用で開き、処理後に閉じる。元ファイルは書き換えない。

## 検証について

26項目すべてについて、同じ解決ロジックを Python に移植して実データで確認済み。
定義どおりの行・列に到達し、総括表の現在値と一致することを確認した（26/26）。
ただし **VBA 自体の実行確認は行っていない**（作成環境に Excel が無いため）。
最初は必ず `照合実行` から試し、いきなり `転記実行` しないこと。

# シート間リンクの数式化（M_Link）

`06 土工事・舗装復旧` の **総括表（土工事）** は、試掘シート・管工シートから
値を1本ずつ手でリンクしている（85本）。列が口径に対応しているので、
口径の部分を差し替えられる形にすれば、工事が変わっても繋ぎ変えが要らない。

さらに、**今は空欄の口径列にも同じ数式を入れておく**。次の工事でその口径を
使ったときに自動で値が出る。使っていない口径のシートは空なので `0` が返る。

## マクロ

| マクロ名 | 動き |
|---|---|
| `リンク設定を取り込む` | 今あるリンクを読み取って「リンク設定」シートを作る |
| `直接リンクで数式を作る` | `='試掘（舗400'!P4` の形。**推奨** |
| `INDIRECTで数式を作る` | 設定の口径を変えるだけで繋ぎ変わる形 |
| `リンクを点検` | 参照先が空・シート欠落・張り忘れを調べる |

`M_Link.bas` を標準モジュールに貼り付けて使う。`M_Util.bas` が必要。

## 直接リンクと INDIRECT

| | 直接リンク | INDIRECT |
|---|---|---|
| 数式バーで参照先が読めるか | `='試掘（舗400'!P4` 読める | 読めない |
| 参照元のトレース（矢印） | 効く | 効かない |
| `Ctrl`+`[` でジャンプ | できる | できない |
| 口径を変えるとき | マクロを1回実行 | 設定セルを書き換えるだけ |
| 再計算 | 通常 | 揮発性（毎回再計算） |

**既定は直接リンク。** 計算書を人がチェックする場面で参照先が追えないのは
損失が大きく、INDIRECT の利点は「マクロを再実行しなくてよい」の一点しかない。
口径を変えるのは工事の切り替え時だけなので、その一手間は問題にならない。

どちらも同じ「リンク設定」から生成するので、後から切り替えられる。

## 展開の可否

総括表には2種類の並びが混ざっている。取り込み時に自動で判別する。

**展開可（23群）** — 1つの行に複数の口径列が並ぶ。全ての口径列に数式を入れる。

```
行9  J列(φ50)=試掘（舗50!P4   M列(φ400)=試掘（舗400!P4
     → K列(φ300) L列(φ75) N列(φ600) にも同じ P4 を入れる
```

**展開不可（32群）** — 行ごとに口径が分かれている区間。今ある列だけに入れる。

```
行31-33  R列(φ50)  ← 管工（舗50!T16,T17,T18
行36,38  S列(φ75)  ← 管工（舗75!T16,T17
行41-43  T列(φ400) ← 管工（舗400!T16,T17,T18
```

同じ参照セル（T16 など）を複数の行が分け合っているかどうかで判別する。
ここへ一律に入れると二重計上になる。

**対象外（3群）** — `管工（土量1）` の行213・216・217。口径によってシートの
行数が違うため、列ごとに参照セルが違う（S→AB13 / T→AB12 など）。
1つのテンプレートでは書けないので、書き込まず手作業のまま残す。

## 口径対応表

取り込むと、リンクのある列だけでなく**同じ系統の全ての列**が並ぶ。
系統は見出しの「（」より前で判定する（`試 掘 （400-500）` → `試掘`）。

| 列 | 見出し | 口径 | 系統 | 備考 |
|---|---|---|---|---|
| J | 試 掘 （PE50-300)新設 | 50 | 試掘 | |
| K | 試 掘 （200-300） 新設 | 300 | 試掘 | ★推定値 |
| L | 試 掘 （75-300） 取替・撤去 | 75 | 試掘 | ★推定値 |
| M | 試 掘 （400-500） | 400 | 試掘 | |
| N | 試 掘 （600以上） | 600 | 試掘 | ★推定値 |
| R | 管工事 （PE50-300)新設 | 50 | 管工事 | |
| S | 管工事 （75-300） 取替・撤去 | 75 | 管工事 | |
| T | 管工事 （400-500） | 400 | 管工事 | |
| U | 管工事 （600以上） | 600 | 管工事 | ★推定値 |

リンクの無い列（K・L・N・U）の口径は、見出しの数字とブックにあるシート名を
突き合わせて推定する。**★の付いたものは必ず目で確かめること。**
口径が空欄の列には数式を入れない。

## 使い方

1. `リンク設定を取り込む` → 対象シート名は `総括表（土工事）`
2. 口径対応表の★と空欄を確かめる
3. `直接リンクで数式を作る` → バックアップを作ってから書き込む
4. **総括表の数値が1つも変わらないのが正解**（`BK_` シートと見比べる）

口径を変えるときは、口径対応表を直してから 3 をもう一度実行する。

## この工事での結果

| 項目 | 値 |
|---|---|
| リンク群 | 58群（85セル） |
| 展開可 | 23群 |
| 展開不可 | 32群 |
| 対象外 | 3群（7セル） |
| 書き込むセル | 142個（既存78 + 新規64） |

新規64個は**すべて 0** が入る。この工事では数値が1つも変わらない。
効果が出るのは、φ300 や φ600 を使う次の工事から。

## 注意点

- INDIRECT 形式にした場合、シート名を変えると壊れる。試掘・管工シートの
  名前は変更しないこと
- 総括表（土工事）の行26-50・行51-65 には、見出しの無い5つのブロックがある
  （H26:H30 などが結合されているが中身が空）。ブロックと口径の対応が
  シート上から読み取れないため、空のブロックには数式を入れていない

## 検証について

`excel/docs/verify_link_formulas.py` で、取り込みから数式生成までを同じ
ロジックで再現し、次を確認済み。

- 既存のリンクがあるセル78個 … 生成後も値が変わらない
- 新しく入るセル64個 … すべて 0
- 対象外の3群 … 書き込まれない

**VBA 自体の実行確認は行っていない。**
