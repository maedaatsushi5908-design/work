# 総括表 自動転記・照合マクロ

`01 総括表` の数量を、`02`〜`08` の各数量計算書から自動で拾って入れる。
入れる前に必ず差分を見せ、書き込む前に総括表のバックアップを取る。

対象: 東白川特２高層配水池揚水管取替工事（ただし他工事にも流用できる設計）

## できること

| マクロ名 | 動き |
|---|---|
| `定義シートを作成` | 転記のルールを書いた「転記定義」シートを作る。**最初に一度だけ** |
| `照合実行` | **書き換えない。** 総括表の値と計算値を突き合わせ、「照合結果」シートに一覧を出す |
| `転記実行` | 差分を見せて確認を取り、OKならバックアップを作ってから書き込む |

総括表の数量40項目のうち、**26項目が自動転記の対象**。残り14項目（仕切弁・空気弁・
フランジ継手など）は図面から数える手入力項目なので、照合結果に「手入力」として
現在値だけ表示する。

## 導入手順

### 1. 総括表を .xlsm で保存し直す

`01 総括表...xlsx` を開き、**ファイル → 名前を付けて保存 → ファイルの種類を
「Excel マクロ有効ブック (*.xlsm)」** にして保存する。
`.xlsx` のままではマクロを保存できない。

### 2. VBE を開く

`Alt` + `F11`

### 3. モジュールを入れる

4つのファイルを取り込む。**コピー＆貼り付けを勧める**（文字化けしないため）。

1. VBE のメニュー → **挿入 → 標準モジュール**
2. GitHub 上で `M_Util.bas` を開き、中身を全部コピー
3. さきほどの標準モジュールに貼り付け
4. `M_Config.bas` `M_Engine.bas` `M_Main.bas` も同様に、**それぞれ別の標準モジュール**に貼り付ける

**先頭の `Attribute VB_Name = "..."` の行は必ず削除すること。**
この行が消えるのはインポートしたときだけで、貼り付けでは残り、
コード画面では無効な行なのでコンパイルエラーになる。
モジュール名はプロパティウィンドウの `(オブジェクト名)` で `M_Util` などに直す。

> インポート機能（ファイル → ファイルのインポート）を使いたい場合は、
> `sjis/` フォルダの方の `.bas` を使うこと。こちらは Shift-JIS で保存してあるので
> 日本語が化けない。

### 4. 転記元ファイルを同じフォルダに置く

`01`（総括表）と `02`〜`08` を**同じフォルダ**に入れておく。
ファイル名は元の日本語名のままでよい。**先頭の番号（`02` `05-1` など）で
探す**ようにしてあるので、`02　東白川　鋳鉄管製造　数量計算書.xls` でも見つかる。

別フォルダにある場合は、実行時にフォルダを尋ねてくる。

### 5. 定義シートを作る

`Alt` + `F8` → `定義シートを作成` → 実行

「転記定義」シートができる。中身を見れば、どこから何を拾っているかが全部分かる。

## 使い方

### まず照合

`Alt` + `F8` → `照合実行`

「照合結果」シートに一覧が出る。

| 判定 | 意味 |
|---|---|
| 一致 | 総括表の値＝計算値。問題なし |
| 差異 | ずれている。**転記ミスか、計算書側が更新された** |
| 手入力 | 自動化対象外。現在値のみ表示 |
| エラー | 元ファイルが無い／シート名やキーが変わった |

### 問題なければ転記

`Alt` + `F8` → `転記実行`

差分の件数を出して確認を求める。OKすると `BK_日付時刻` という
バックアップシートを作ってから書き込む。元に戻したいときはこれを見る。

## 他の工事に流用するには

**コードは触らない。「転記定義」シートを直すだけ。**

| 列 | 意味 |
|---|---|
| 有効 | 空欄か `×` にするとその行を無視する |
| 区分 | `自動転記` か `手入力` |
| 名称／摘要 | 総括表での表記。転記先セルの中身と合っているか自動で点検する |
| 転記先セル | 総括表のセル番地（例 `D10`） |
| 元ファイル／元シート | 転記元。ファイル名は先頭番号が合えばよい |
| キー1列／キー1／キー1方式 | 行を探す1つ目の手がかり。**結合セルで下が空でも上から補完する** |
| キー2列／キー2／キー2方式 | 行を絞る2つ目の手がかり |
| 行オフセット | 見つけた行からの相対行（`合 計` の次行を読む場合は `1`） |
| 値列 | 値がある列（`F` `AO` など） |
| 見出し行／見出しキー | 列を見出しから探す場合に使う（口径ごとに列が変わる表など） |
| 丸め | 小数点以下の桁数。空欄なら丸めない |

照合方式は3種類。

- `部分` … 表記ゆれを吸収して部分一致（既定）
- `完全` … 完全一致。`SP400A` と `φ400` を区別したいときなど
- `口径` … 数字だけ取り出して数値比較。`400A` `φ400用` `φ400 1種管` がすべて 400 として一致する

比較の前に、全角→半角・空白除去・`φ` 除去・大文字化を行うので、
`ＧＸ形 直 管` と `GX形直管` は同じものとして扱われる。

## 注意点

- **`03` 切管表の φ400 は最終シート `GX　400 (4)` の合計を使っている。**
  シートを増やした場合は定義シートの元シート名を直すこと。
- **`05-1` は `延長集計表  採用(伏越削除)` を見ている。**
  よく似た `延長集計表` シートもあるが、そちらは採用前の版。
- 挿口加工費は `02` の「GX形 挿口リング」から取っているが、
  `03` 切管表の W列 とも一致するはず。ずれたらどちらかが古い。
- 総括表の `K173:K178` にある VLOOKUP は参照先 `O173:R204` が空で、
  常に空白を返す。使われていないので消してよい。
- 転記元ブックは読み取り専用で開き、処理後に閉じる。元ファイルは書き換えない。

## 検証について

26項目すべてについて、同じ解決ロジックを Python に移植して実データで確認済み。
定義どおりの行・列に到達し、総括表の現在値と一致することを確認した（26/26）。
ただし **VBA 自体の実行確認は行っていない**（作成環境に Excel が無いため）。
最初は必ず `照合実行` から試し、いきなり `転記実行` しないこと。

# シート間リンクの数式化（M_Link）

`06 土工事・舗装復旧` の **総括表（土工事）** は、試掘シート・管工シートから
値を1本ずつ手でリンクしている（85本）。これを数式に置き換える。

## マクロは1本だけ

```
総括表の数式を作り直す
```

中でやること:

1. 今あるリンクを読み取って「リンク設定」シートを作る
   （前回の設定があれば、口径などの手直しは引き継ぐ）
2. 何をするかを表示して確認を取る
3. バックアップシートを作ってから数式を書き込む
4. **値が変わったセルを一覧にして表示**し、納得できなければその場で元に戻す

確認も点検も取り消しも、この1本の中に入っている。
`M_Link.bas` を標準モジュールに貼り付けて使う。`M_Util.bas` が必要。

## 2種類の数式

取り込み時にどちらを使うか自動で割り当てる。設定シートの「方式」欄で変更できる。

### 直接（並びが固定の箇所）

```
='試掘（舗400'!P4
```

舗装切断工のように、転記元の行が `t≦15` `15<t≦30` `30<t≦40` と固定文字で
並ぶ箇所。セルの位置が動かないので直接参照でよい。この工事では69箇所。

### 条件式（舗装厚で照合する箇所）

```
=SUMIFS('管工（舗50'!$T$16:$T$22,'管工（舗50'!$R$16:$R$22,$I31)
```

**舗装版破砕工のブロックは危険。** 転記元の舗装厚は、その工事で実際に出てくる
ものだけが詰めて並ぶ。

```
R16: =IF(MAX($E$389:$E$428)<ROW()-15,"",INDEX($D$389:$D$428,MATCH(ROW()-15,$E$389:$E$428,0),1))
```

実際に工事・口径で並びが違う。

| シート | R16 | R17 | R18 | R19 |
|---|---|---|---|---|
| `管工（舗50` | 4 | 5 | 10 | (空) |
| `管工（舗400` | 4 | 5 | 10 | **15** |
| `試掘（舗50` | 4 | **10** | (空) | (空) |
| `試掘（舗400` | 4 | 10 | 15 | (空) |

`試掘（舗50` には 5cm が無いので、`P12` は 10cm の数量になる。
固定セル参照では、5cm の行が 10cm の数量を拾ってしまう。

条件式なら、総括表の厚さ欄（I列）と一致する行だけを合計するので間違えない。
その厚さが転記元に無ければ 0 になる。種別が `As ・ Co` の行は両側を足す。

## ブロックの自動検出

転記元の列の並びは系統ごとに違うが、設定は要らない。見出しから探す。

1. `□舗装版破砕工` を含むセルを探す（数式なら計算結果で判定）
2. そのすぐ下で `種別・舗装厚` と `合 計` が並ぶ行を見つける
3. 各 `種別・舗装厚` の右にある最初の `合 計` を対にする。舗装厚列は種別列の隣
4. データ行は、種別列に `As` / `Co` が並ぶ範囲

| シート | ブロック行 | As(厚,合計) | Co(厚,合計) |
|---|---|---|---|
| `管工（舗xx` | 16〜22 | R, T | V, X |
| `試掘（舗xx` | 11〜16 | O, P | R, S |
| `給水(舗` | 10〜15 | R, T | W, Y |
| `仮配（舗` | 10〜16 | R, W | — |

## 展開の可否

| 区分 | 数 | 動き |
|---|---|---|
| 展開可 | 23群 | 同じ系統の全ての口径列に入れる |
| 展開不可 | 32群 | 今ある列だけに入れる |
| 対象外 | 3群 | 書き込まない |

**展開不可** は行ごとに口径が分かれている区間（行31-33がR列、行36,38がS列、
行41-43がT列）。同じ参照セルを複数の行が分け合うかで判別する。一律に入れると
二重計上になる。

**対象外** は `管工（土量1）` の行213・216・217。口径でシートの行数が違い、
列ごとに参照セルが異なる（S→AB13 / T→AB12）。1つのテンプレートでは書けない。

## リンク設定シート

実行のたびに作り直されるが、**手直しした内容は引き継ぐ**。

| 欄 | 意味 |
|---|---|
| 厚さ列 / 種別列 | 総括表のどの列を見るか（既定 I / E） |
| 口径対応表 | 列 → 参照するシートの口径。★は見出しからの推定値 |
| 有効 | 空欄にするとその行は書き換えない |
| 展開 | ○なら同じ系統の全ての口径列に入れる |
| 方式 | `直接` または `条件式` |

設定を直してから、もう一度マクロを実行すれば反映される。

## INDIRECT について

一時は INDIRECT 形式も用意したが**外した**。数式バーで参照先が読めず、
参照元のトレースも `Ctrl`+`[` も効かない。利点は「マクロを再実行しなくてよい」
の一点だけで、口径を変えるのは工事の切り替え時だけなので割に合わない。

ただし**読み戻しには対応している**。以前 INDIRECT 形式にした総括表でも
そのまま実行できる（`Normalize` が普通の参照に読み替える）。

## 見つかった不整合

`試掘（舗50` には 5cm が無く、`P12` は 10cm の数量（1.2）。
ところが総括表の **行14（I列=5）** がその `P12` を参照している。
本来 1.2 は **行15（I列=10）** に入るべき値。

計の行（17行目）で合算されるため総量は合っているが、厚さ別の内訳が
1段ずれている。舗装版破砕は厚さで単価が変わるので、要確認。

条件式にすると 行14 は 0 になり、行15 に 1.2 が入る。
実行後の「実行結果」シートに、この2セルが変更として出る。
