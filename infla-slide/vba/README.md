# VBAモジュール（コピペ用）

エスティマ「スライド用csv出力」のCSV2本から、インフレスライド計算表を作るマクロです。

## 貼り付け手順

1. Excelで新規ブックを作り、**マクロ有効ブック（.xlsm）** として保存する
2. `Alt + F11` でVBE（Visual Basic Editor）を開く
3. メニュー「挿入 → 標準モジュール」
4. 下表のファイルをGitHubで開き、右上の **Raw** を押す → `Ctrl+A` → `Ctrl+C`
5. VBEの標準モジュールに `Ctrl+V` で貼り付ける
6. プロパティウィンドウ（`F4`）の **(オブジェクト名)** をモジュール名に変更する
7. モジュール分くり返す

| ファイル | モジュール名 | 役割 | 必須 |
|---|---|---|:---:|
| `M00_Main.bas` | `M00_Main` | メイン処理・CSV読み込み・2本の突合 | ● |
| `M10_CsvIO.bas` | `M10_CsvIO` | CSV読み書き・数値／文字列変換 | ● |
| `M20_Slide.bas` | `M20_Slide` | 設定シート生成・計算表の本体と体裁 | ● |
| `M30_Shokeihi.bas` | `M30_Shokeihi` | 諸経費部（直接工事費計〜工事費）とスライド額 | ● |
| `M90_SampleData.bas` | `M90_SampleData` | 動作確認用サンプルCSV生成 | 任意 |
| `M91_TemplateDump.bas` | `M91_TemplateDump` | シートの体裁をテキストに書き出す | 任意 |

> `Attribute VB_Name = "..."` の行は**わざと入れていません**（コピペで貼るとエラーになるため）。
> **参照設定の追加は不要です。** Dictionary・ADODB.Stream はすべて `CreateObject` で呼んでいます。

## 実行手順

| # | マクロ名 | 内容 |
|---|---|---|
| 1 | `設定シート作成` | 「設定」シートを作る。工事名・請負代金額・基準日などを入力 |
| 2 | `テスト用CSV作成` | （任意）エスティマ形式のサンプルCSVを2本作る |
| 3 | `スライド計算表作成` | 旧単価CSV → 新単価CSV の順に選ぶと計算表ができる |

## CSVの出し方

エスティマの `機能 → CSV連携 → 抽出指示ファイル「スライド用csv出力」` から、
**単価適用日を変えて2回出力**します。

| | 単価適用日 | ファイル |
|---|---|---|
| 旧単価 | 当初 | `〜_旧単価.csv` |
| 新単価 | 基準日 | `〜_新単価.csv` |

| **U** | **処分費単価（スライド前）** | **★手入力（黄色）** |

| W〜Z | 処分費額（4系列） | O列に〇がある行だけ計算 |

### 処分費単価の手入力について

課の運用で**処分費と運搬費の合算金額**がCSVに出てくるため、処分費だけを手打ちする欄を設けています。

- **U列に処分費分の単価だけを入れる** → その単価で処分費額（W〜Z列）を計算します
- **空欄のまま** → その行の設計単価を全額処分費として計算します（従来と同じ挙動）
- V列（スライド後）が空欄なら U列の値を使います。処分費は据置のことが多いのでU列だけ入れれば足ります

処分費額は共通仮設費率分の対象減額分（3%ルール）の計算にだけ使い、
P〜S列の工事費そのものには影響しません。

### 「スライド後・全体」の考え方

```
R（スライド後・全体） = Q（出来形分は旧単価のまま） + S（残工事分は新単価）
```

参考ファイルでは `=K*J`（全体×新単価）としたうえで、施工済みの行だけ手作業で
`=K*I` に直していましたが、上の式にすると**その手直しが不要**になります。
出来形＝全体の行は自動的に旧単価のまま、出来形0の行は自動的に全体が新単価になります。

## 諸経費部

直接工事費計 → 処分費 → 共通仮設費率分 → 共通仮設費計 → 純工事費計 →
現場管理費 → 工事原価計 → 一般管理費 → 工事価格 → 消費税相当額 → 工事費
を、スライド前全体／前出来形／後全体／後残工事 の4系列で計算します。

率式（神戸市・道路改良工事等）は**設定シートで変更できます**。

```
共通仮設費率 = ROUND(1228.3 × 対象額 ^ (-0.2614), 2)
　　補正後   = ROUND(ROUND(率 × 1.2, 2) × 1.04, 2)
現場管理費率 = ROUND(458.2 × 対象額 ^ (-0.1508), 2)
　　補正後   = ROUND(ROUND(率 × 1.1, 2) × 1.06, 2)
一般管理費率 = ROUND(-5.48972 × LOG10(対象額) + 59.4977, 2)
契約保障費   = ROUNDDOWN(一般管理費率対象額 × 0.0004, 0)
```

率はスライド前とスライド後で別々に計算します（対象額が変わるため）。
出来形列は前全体と同じ率、残工事列は後全体と同じ率を使います（参考ファイルと同じ扱い）。

技術管理費の行が見つからない場合など、確認が必要な行は**摘要欄に赤字で★印**を出します。

## 動作確認済みの内容

サンプルCSV2本で全数式を実際に計算させ、次を確認しています。

- 階層（費目→工事区分→工種→種別→細別→明細）の集計が正しく積み上がる
- 施工済み行（出来形＝全体）はスライド後も旧単価のまま、残工事が0になる
- 処分費単価を手入力した行は、その単価で処分費額が計算される（設計単価は使われない）
- 共通仮設費率分対象額 ＝ 直接工事費計 ＋ 積上げ分の処分費 － 技術管理費
- 諸経費の率式が4系列それぞれで計算され、工事費まで通る
- 循環参照・参照エラーが無い

## まだ確認が必要なこと

- **スライド額の最終的な出し方**。いまは「スライド後の工事費（全体）－ スライド前の工事費（全体）
  － 請負代金額の1%」で変更額を出していますが、課の運用に合わせて直す必要があるかもしれません
- Zコード（諸経費）の並びは実物のCSVを見ていないため、順序や項目名が合わない可能性があります
- 共通仮設費率の係数は工種区分で変わります（参考ファイルは「道路改良工事・公園工事等」）
