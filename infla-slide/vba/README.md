# VBAモジュール（コピペ用）

**はじめての方は [`../docs/使い方.md`](../docs/使い方.md) を見てください。**
このファイルは仕様のリファレンスです。


エスティマ「スライド用csv出力」のCSV2本から、**スライド計算表 → 経費計算シート → スライド調書（様式4-2号）** の3シートを作るマクロです。

## 貼り付け手順

1. Excelで新規ブックを作り、**マクロ有効ブック（.xlsm）** として保存する
2. `Alt + F11` でVBE（Visual Basic Editor）を開く
3. メニュー「挿入 → 標準モジュール」
4. 下表のファイルをGitHubで開き、右上の **Raw** を押す → `Ctrl+A` → `Ctrl+C`
5. VBEの標準モジュールに `Ctrl+V` で貼り付ける
6. プロパティウィンドウ（`F4`）の **(オブジェクト名)** をモジュール名に変更する
7. モジュール分くり返す

| ファイル | モジュール名 | 役割 | 必須 |
|---|---|---|:---:|
| **`ALL_IN_ONE.bas`** | 何でも可 | **下の5つを1つにまとめたもの。これ1つ貼れば動きます** | ◎ |
| `M00_Main.bas` | `M00_Main` | メイン処理・CSV読み込み・2本の突合 | ● |
| `M10_CsvIO.bas` | `M10_CsvIO` | CSV読み書き・数値／文字列変換 | ● |
| `M20_Slide.bas` | `M20_Slide` | 設定シート生成・スライド計算表（明細＋経費計算） | ● |
| `M40_Chosho.bas` | `M40_Chosho` | スライド調書（様式4-2号） | ● |
| `M90_SampleData.bas` | `M90_SampleData` | 動作確認用サンプルCSV生成 | 任意 |
↑ `ALL_IN_ONE.bas` を使う場合、上の M00〜M90 は貼り付け不要です（両方入れると名前が重複します）
| `M91_TemplateDump.bas` | `M91_TemplateDump` | シートの体裁をテキストに書き出す | 任意 |

> `Attribute VB_Name = "..."` の行は**わざと入れていません**（コピペで貼るとエラーになるため）。
> **参照設定の追加は不要です。**

## 実行手順

| # | マクロ名 | 内容 |
|---|---|---|
| 1 | `設定シート作成` | 「設定」シートを作る。工事名・請負代金額・基準日などを入力 |
| 2 | `テスト用CSV作成` | （任意）エスティマ形式のサンプルCSVを2本作る |
| 3 | `スライド計算表作成` | 旧単価CSV → 新単価CSV の順に選ぶと3シートができる |

## CSVの出し方

`機能 → CSV連携 → 抽出指示ファイル「スライド用csv出力」` から、**単価適用日を変えて2回**出力します。

| | 単価適用日 |
|---|---|
| 旧単価CSV | 当初 |
| 新単価CSV | 基準日 |

## 手入力するところ（すべて黄色セル）

### スライド計算表

| 列 | 項目 | 内容 |
|:---:|---|---|
| **L** | 数量（出来形） | 出来高検査の結果を入力。M列の残工事は `=K-L` で自動 |
| **O** | 処分費〇 | 処分費対象の行に `〇` |
| **P** | 管材費〇 | 水道工事の管材費の行に `〇`（⑥共通仮設費対象額で 1/2 を控除します） |
| **Q** | **新工種〇** | **基準日以降に追加された新工種の行に `〇`** |
| **X** | 処分費単価（スライド前） | 処分費と運搬費の合算単価から**処分費分だけ**を入力。空欄ならその行の設計単価を全額処分費とみなす |
| **Y** | 処分費単価（スライド後） | 空欄ならX列の値を使う。処分費は据置が多いのでX列だけで足ります |

### 経費計算シート

| 項目 | 内容 |
|---|---|
| ⑦⑪⑮ 経費率 | 神戸市の率式で自動計算した値が入ります。**積算システムの値があれば上書き**してください |
| ⑯契約保証費 | 当初設計時の額で固定 |

### スライド調書（様式4-2号）

| 項目 | 内容 |
|---|---|
| I8 請負率(%) | 設定シートの請負代金額から自動で入りますが、上書きできます |

## 新工種〇 と 受注者負担1%

受注者負担1%の母数は、**請負ベースの残工事から新工種を抜いた額（P1''）**です。

```
P1'  = 請負工事価格 − 出来高（請負率考慮）          … 残工事
P1'' = 新工種抜き   − 新工種抜き出来高（請負率考慮） … 1%の母数
S'   = P2' − P1' − P1'' × 1%      （増額スライドの場合）
     = P2' − P1' + P1'' × 1%      （減額スライドの場合）
```

Q列に `〇` を付けた行は、経費計算シートの **H列（新工種抜き）・I列（新工種抜き出来高）** から
直接工事費・管材費・処分費・積上分のすべてで除外され、その経費率も別に計算されます。

サンプルで確認した効果：

```
P1'  （残工事）              39,624,752 → 1%は 396,248 円
P1'' （新工種を抜いた残工事） 29,293,115 → 1%は 292,931 円
                                         受注者負担が 103,316 円 軽くなる
```

## 作られるシート

### 1. スライド計算表（明細）

| 列 | 項目 | |
|:---:|---|---|
| A | コード | 非表示にして構いません |
| B〜F | 費目／工事区分／工種／種別／細別 | ①②③④のマーカーで階層を表現 |
| G / H | 施工単価名称 / 規格 | |
| I / J | 単価（スライド前 / スライド後） | 旧単価CSV / 新単価CSV |
| K / **L** / M | 数量（全体 / **出来形** / 残工事） | |
| N | 単位 | |
| **O / P / Q** | **処分費〇 / 管材費〇 / 新工種〇** | |
| R | スクラップ〇 | CSVから自動判定（修正可） |
| S / T / U | スライド前（全体 `=K*I` / 出来形 `=L*I` / 残工事 `=M*I`） | |
| V / W | スライド後（全体 `=K*J` / 残工事 `=M*J`） | |
| X | 摘要 | |
| **Y / Z** | **処分費単価（前 / 後）** | |
| AA〜AE | 処分費額（5系列） | O列に〇がある行だけ計算 |

### 2. 経費計算シート

`203_経費計算シート` と同じ並びで、直接工事費〜工事費を9系列で計算します。

| 記号 | 名称 | 経費率 |
|:---:|---|---|
| A | 変更設計書（全体） | 旧（自前） |
| B / C / D | 残工事 / 単価更新残工事 / 出来高 | 素材のみ |
| E | スライド設計書（全体・新単価） | 新（自前） |
| F | 単価更新設計書 残工事【経費計算】 | E列の率 |
| G | 変更設計書 出来高【経費計算】 | A列の率 |
| **H** | **変更設計書 新工種抜き（全体）** | 新工種抜き（自前） |
| **I** | **新工種抜き 出来高** | H列の率 |

自前の率を持つのは A・E・H の3列だけです。
**積算システムで率を取る場合でも3回で済みます（元は設計書(1)〜(9)の9系統）。**

### 3. スライド調書（様式4-2号）

経費計算シートの ㉑'工事価格（スクラップ込み）を転記して、P1'・P2'・P1''・S' を計算します。

## 動作確認済みの内容

サンプルCSV2本で全数式を実際に計算させ、次を確認しています。

- 階層（費目→工事区分→工種→種別→細別→明細）の集計が正しく積み上がる
- 処分費単価を手入力した行は、合算単価ではなくその単価で処分費額が計算される
- 管材費〇の行が ①' として集計され、⑥⑩で 1/2 が控除される
- **スクラップ行が自動判定され、①直接工事費・④'その他積上から外れて ㉒ に集計される**
- **新工種〇の行が H・I 列（新工種抜き）から除外される**
- ③率対象外費の算式が、元ファイルの実データ6系列すべてと一致する
- ⑲端数整理を含めて工事価格が1000円単位で揃う
- 様式4-2号の P1'・P2'・P1''・S' が通り、増額／減額の判定が出る
- 循環参照・参照エラーが無い

## まだ確認が必要なこと

- **⑯契約保証費**は当初設計時額の手入力です。積算システムから取れるなら教えてください
- 経費率の自動計算式は「道路改良工事・公園工事等」の係数です。工種区分が違う場合は
  設定シートの係数を変えるか、経費計算シートの率セルを直接上書きしてください
- Zコード（共通仮設費の積上分）は ④運搬費・⑤技術管理費 を名称で探し、
  それ以外は ④'その他 にまとめています。実物のCSVで項目名がずれていたら教えてください
