# VBAモジュール（コピペ用）

## 貼り付け手順

1. Excelで新規ブックを作り、**マクロ有効ブック（.xlsm）** として保存する
2. `Alt + F11` でVBE（Visual Basic Editor）を開く
3. メニュー「挿入 → 標準モジュール」
4. 下表のファイルをGitHubで開き、右上の **Raw** を押す → `Ctrl+A` → `Ctrl+C`
5. VBEの標準モジュールに `Ctrl+V` で貼り付ける
6. プロパティウィンドウ（`F4`）の **(オブジェクト名)** をモジュール名に変更する
7. 4モジュール分くり返す

| ファイル | モジュール名 | 役割 | 必須 |
|---|---|---|:---:|
| `M00_Main.bas` | `M00_Main` | メイン処理・設定読み込み・CSV突合 | ● |
| `M10_CsvIO.bas` | `M10_CsvIO` | CSV読み書き・数値／文字列変換 | ● |
| `M20_Report.bas` | `M20_Report` | 設定シート生成・設計書出力と体裁 | ● |
| `M90_SampleData.bas` | `M90_SampleData` | 動作確認用サンプルCSV生成 | 任意 |

> `Attribute VB_Name = "..."` の行は**わざと入れていません**。
> コピペで貼るとその行がエラーになるためです。モジュール名は手順6で設定してください。
>
> **参照設定の追加は不要です。** Dictionary・ADODB.Stream はすべて `CreateObject` で呼んでいます。

## 実行手順

| # | マクロ名 | 内容 |
|---|---|---|
| 1 | `設定シート作成` | 「設定」シートを作る。工事情報とCSVの列番号を入力する |
| 2 | `テスト用CSV作成` | （任意）サンプルCSVを2本作り、設定も自動で埋める |
| 3 | `インフレスライド設計書作成` | 設計書シート一式を作成する |

`Alt + F8` のマクロ一覧から実行できます。

## 出力されるシート

| シート | 内容 |
|---|---|
| `01_表紙` | 工事概要・請負代金額・変更額・変更後請負代金額 |
| `02_総括表` | 工種別の変動前／変動後／差額 ＋ スライド額の算出過程 |
| `03_対比表` | 明細ごとに変動前・変動後を左右に並べ、差額を表示 |
| `04_変動前内訳書` | 旧単価での内訳 |
| `05_変動後内訳書` | 新単価での内訳 |

## 設定シートの主な項目

| 区分 | 項目 | 備考 |
|---|---|---|
| 工事情報 | 工事名／工事場所／工期／請負代金額／基準日／発注者／受注者 | 表紙・総括表に反映 |
| CSV設定 | 変動前CSVパス／変動後CSVパス | 空欄ならダイアログで選択 |
| | 文字コード | 既定 `Shift_JIS`。UTF-8なら `UTF-8` |
| | 見出し行数 | データ開始前の行数 |
| 列マッピング | 工種列／種別列／細別列／規格列／単位列／数量列／単価列／金額列／摘要列 | **CSVの何列目か（1＝A列）**。使わない項目は `0` |
| 計算設定 | 受注者負担率 | 既定 `0.01`（請負代金額の1%） |
| | 端数処理／端数単位 | 切り捨て／切り上げ／四捨五入 |
| 除外語 | 合計・小計・総計・計・直接工事費 | この語と一致する行は集計から除外（二重計上の防止） |

**積算システムのCSVの列が違っていても、コードを直さず設定シートの列番号を変えるだけで合わせられます。**

## 突合のしくみ

変動前・変動後の明細を

```
工種 ｜ 種別 ｜ 細別 ｜ 規格 ｜ 単位
```

の5項目を連結したキーで突き合わせます（全角半角・空白の差は吸収）。
片方にしか無い明細も、もう一方を 0 として差額に含めます。
同じキーの行が複数あるときは数量・金額を合算し、単価は 金額÷数量 で再計算します。

## 計算式

```
P1（変動前残工事代金額） = Σ 変動前金額
P2（変動後残工事代金額） = Σ 変動後金額

スライド差額   = P2 - P1
受注者負担額   = 請負代金額 × 受注者負担率（端数処理あり）
変更額         = スライド差額 - 受注者負担額   ※マイナスのときは 0
変更後請負代金額 = 請負代金額 + 変更額
```

## 既知の制限・要確認

- 発注機関（都道府県・政令市）の指定様式に合わせた**罫線・押印欄・項目の並びは未反映**です。
  テンプレートを `infla-slide/input/` にアップロードしてもらえれば、そこに合わせて作り直します。
- 出来高（既済部分）の控除は、**積算システム側で残工事量として出力済み**であることを前提にしています。
  CSVが当初数量のままの場合は、出来高を入力するシートを追加する必要があります。
- 諸経費（共通仮設費・現場管理費・一般管理費）は、CSVに計上済みの金額行として入っている前提で、
  そのまま明細と同じ扱いで集計しています。
- スライド差額がマイナス（デフレ方向）の場合の扱いは未確定のため、変更額を 0 に丸めています。
