# 積算システム出力CSV「スライド用csv出力」の仕様

`単価調整Excel（VBA格納ファイル）20260817.xlsm` に格納されていたVBA（Module2／1855行）を
解析して復元した仕様です。**CSV実物は見ずに、VBAの処理内容から逆算しています。**

- 積算システム：**エスティマ**
- 出力手順：`機能 → CSV連携 → 抽出指示ファイル「スライド用csv出力」→ csv抽出`
- 発注機関：**神戸市**（VBA内に「神戸市単価が含まれるため扱いに注意」の記載）

---

## 1. 列の構成（12列・見出し行なし）

VBAは読み込んだCSVに対し `Columns("A:B").Insert` で2列、`Rows("1:2").Insert` で2行を挿入し、
そのうえで見出しを付けています。**挿入後のC列＝元のA列**なので、逆算すると次のとおりです。

| CSV列 | 挿入後 | 項目 | 備考 |
|:---:|:---:|---|---|
| A | C | **コード** | 行の種類を表す。後述 |
| B | D | **施工単価名称** | |
| C | E | **単位** | ※VBAの見出しは「単価」だが**誤記**。`Range("E" & r) = "式"` と単位を書き込んでいる |
| D | F | **規格1** | |
| E | G | **規格2** | |
| F | H | **摘要** | |
| G | I | **設計単価①** | |
| H | J | **設計単価②** | |
| I | K | **数量①** | |
| J | L | **数量②** | |
| K | M | **設計金額①** | |
| L | N | **設計金額②** | |

**見出し行は無く、1行目からデータが始まります。**（VBAが行を挿入して見出しを作っているため）

### ①②が「当初」か「変更」かの判定

VBAは `N列（＝設計金額②）の X1000 の次の行` を見て並び順を判定しています。

```vba
If Range("N" & rx1000 + 1) = 0 Then
    ' ① = 当初、② = 変更
Else
    ' ① = 変更、② = 当初
End If
```

- **当初設計のみのCSV**：②側が全て0 → ①＝当初
- **変更設計を含むCSV**：②側に値あり → **①＝変更、②＝当初**（順序が入れ替わる）

変更履歴にも「変更欄と当初欄が逆になる事象を修正」とあり、この判定は後から入った対策です。
**新しく作るVBAでも同じ判定が必要です。**

## 2. 行の構成（A列のコード体系）

```
┌─────────────────────────────────────┐
│ G****        Gコード（工事区分などの見出し）      │ ← X1000より前
├─────────────────────────────────────┤
│ X1000        本工事費 ＝ 内訳の開始マーカー       │
│   Y10**      L1  工事区分                       │
│   Y20**      L2  工種                           │
│   Y30**      L3  種別                           │
│   Y40**      L4  細別                           │
│   （コードなし/Y以外）  明細行＝単価行             │
├─────────────────────────────────────┤
│ Z0001*       直接工事費（ここから諸経費）         │
│ Z0040*       共通仮設費                          │
│ Z0045*       工事原価計・一般管理費等             │
│ Z0047*       （諸経費計算で参照）                 │
│   YZ****     Zコード配下の内訳明細                │
└─────────────────────────────────────┘
```

### レベル判定ルール（VBA①様式整理レベル表記より）

| コード | レベル |
|---|---|
| `Y10*` | L1 |
| `Y18*` | 工L2（特殊） |
| `Y20*` | L2 |
| `Y30*` | L3 |
| `Y40*` | L4 |
| `Y23*` | **コードの文字数**で決まる：5桁→L1 / 7桁→L2 / 9桁→L3 / 11桁→L4 |

### 明細行（＝単価行）の見分け方

```
レベル欄が空 かつ 施工単価名称がある行
```

VBAでは `If ws1.Range("D" & i) <> "" And ws1.Range("B" & i) = ""` で判定しています
（D＝施工単価名称、B＝レベル）。単価調整の計算も
`If Range("B" & r) = "" And Range("I" & r) <> ""` の行だけを対象にしています。

### CSVに**入っていない**行（VBAが挿入している）

これらはCSVには無く、VBAが後から行挿入で作っています。新規VBAでも同じ処理が要ります。

| 挿入位置 | 挿入される行 |
|---|---|
| `Z0001` の直前 | 直接工事費計 |
| `Z0040` の直前 | 共通仮設費率分／共通仮設費計／純工事費／現場管理費 |
| `Z0045` の直前 | 工事原価計／一般管理費等 |
| 最終行の後 | 工事価格／消費税相当額／工事費 |

## 4. CSV → スライド計算表の対応（これが結論）

| スライド計算表 | 出所 | 自動化 |
|---|---|:---:|
| B 費目 | `X1000` → 「本工事費」 | ○ |
| C 工事区分 | `Y10*`（L1） | ○ |
| D 工種 | `Y20*`（L2） | ○ |
| E 種別 | `Y30*`（L3） | ○ |
| F 細別 | `Y40*`（L4） | ○ |
| G 施工単価名称 | CSV B列 | ○ |
| H 規格 | CSV D列＋E列（規格1＋規格2） | ○ |
| I 単価（スライド前） | **設計単価（当初）** | ○ |
| J 単価（スライド後） | **設計単価（変更）** | ○ |
| K 数量（全体） | 数量（当初） | ○ |
| L 数量（出来形） | — | **手入力** |
| M 数量（残工事） | `=K-L` | ○ |
| N 単位 | CSV C列 | ○ |
| O 処分費 | — | **手入力（〇）** |
| P〜S 金額 | 数式 | ○ |
| T 摘要 | CSV F列 | ○ |

### 重要：CSVは旧単価・新単価で2本必要

CSVは 当初／変更 の2組を持っていますが、**これは「設計変更」の2組であって「単価適用日」の2組ではありません。**
現行のエスティマでは単価適用日を変えた2組を1本のCSVに出力できないため、
**単価適用日を変えて2回出力する**必要があります。

| CSV | 出力条件 | 使う値 |
|---|---|---|
| 旧単価CSV | 当初の単価適用日 | 設計単価 → I列（スライド前）、数量 → K列（全体）、単位・名称・規格・摘要 |
| 新単価CSV | 基準日の単価適用日 | 設計単価 → J列（スライド後） |

2本の突合は、まず行位置で照合し、コード・名称・規格・単位が全行一致すればそのまま採用します。
一致しない場合は 名称｜規格｜単位 をキーに突合し直し、見つからない明細は旧単価を据え置いて警告を出します。

### 手入力が必要な項目

| 列 | 項目 | 理由 |
|---|---|---|
| L | 出来形数量 | 出来高検査の結果から入力 |
| O | 処分費〇 | 処分費対象行の指定 |
| U / V | 処分費単価（スライド前／後） | **処分費と運搬費の合算単価でCSVに出てくるため、処分費分だけを手打ちする**。空欄ならその行の設計単価を全額処分費とみなす |

## 5. 諸経費の計算式（神戸市・道路改良工事等／参考ファイルより）

スライド前（全体・出来形）とスライド後（全体・残工事）の4系列それぞれで同じ計算を回します。

```
処分費            = SUMIF(O列,"〇",金額列)
共通仮設費率分対象額 = 直接工事費計 + SUMIF(準備費の処分費,"〇") - 技術管理費
対象減額分        = IF(処分費 - 対象額*0.03 > 0, 処分費 - 対象額*0.03, 0)
対象額(補正後)    = 対象額 - 対象減額分

共通仮設費率      = ROUND(1228.3 * (対象額-減額分)^(-0.2614), 2)
共通仮設費率(補正) = ROUND(ROUND(率*1.2, 2) * 1.04, 2)         ' 地域補正・週休補正
共通仮設費率分    = ROUNDDOWN(対象額(補正後) * 率(補正)/100, -3)
共通仮設費計      = 共通仮設費率分 + 運搬費 + 準備費 + 技術管理費
純工事費計        = 直接工事費計 + 共通仮設費計

現場管理費率対象額 = ROUNDDOWN(純工事費計 - 対象減額分 - 技術管理費, 0)
現場管理費率      = ROUND(458.2 * (純工事費計-減額分-技術管理費)^(-0.1508), 2)
現場管理費率(補正) = ROUND(ROUND(率*1.1, 2) * 1.06, 2)
現場管理費        = ROUNDDOWN(対象額 * 率(補正)/100, -3)
工事原価計        = 純工事費計 + 現場管理費

一般管理費率対象額 = ROUNDDOWN(工事原価計 - 対象減額分 - 技術管理費, 0)
一般管理費率      = ROUND(-5.48972 * LOG10(工事原価計-減額分-技術管理費) + 59.4977, 2)
契約保障費        = ROUNDDOWN(一般管理費率対象額 * 0.0004, 0)
一般管理費        = 対象額 * 率/100 + 契約保障費

工事価格          = ROUNDDOWN(工事原価計 + 一般管理費 + ｽｸﾗｯﾌﾟ, -3)
消費税相当額      = ROUNDDOWN(工事価格 * 0.1, -1)
工事費            = ROUNDDOWN(工事価格 + 消費税相当額, -1)
```

率は**スライド前とスライド後で別々に計算**されます（対象額が変わるため）。
ただし「出来形」列は率をスライド前と同じ値に固定しています（`R202 = Q202` など）。

## 6. 参考ファイルで見つかった不具合・注意点

| 箇所 | 内容 |
|---|---|
| 例シート R198 の R列 | `=SUMIF(O8:O198,"〇",R8:R198)` と**自分自身の行まで範囲に含んでいる**。他の3列は `O8:O197` なので範囲がずれています |
| 例シート R42・R43 の S列 | `=K42*$I$42` とスライド**前**単価を参照。出来形＝全体（施工済み）の行なのでスライドさせない意図と思われますが、他の行と式が違うので手作業の跡です |
| 例シート R204 の T列 | 数式ではなく `10424000` の**べた値**が入っています |
| 例シート R218 の S列 | `=M218*J218` と残工事数量を参照（他行は `K*$J$`）。ｽｸﾗｯﾌﾟはマイナス数量なので意図的かもしれません |
| VBA E2の見出し | 「単価」となっているが実体は**単位** |
| VBA ④諸経費計算 | 作者自身が「うまく動作しない可能性が高いので注意」とコメントしています |
