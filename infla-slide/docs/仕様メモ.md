# インフレスライド設計書 — 仕様メモ（たたき台）

> 一般的な運用を前提に整理したものです。**実際の発注機関の運用と違う箇所は赤入れしてください。**
> ここが固まれば、あとはCSVの列を合わせるだけでVBAが書けます。

## 1. 根拠と基本の考え方

- 公共工事標準請負契約約款 第26条第6項（インフレスライド条項）
- **基準日以降に施工する残工事**を対象に、旧単価と新単価で積算し直した差額を請負代金額に反映する
- 差額のうち、請負代金額の **1/100（1%）** は受注者負担として控除する

## 2. 計算の流れ

| # | 手順 | 備考 |
|---|---|---|
| 1 | 基準日を決定 | 原則、受注者の請求日 |
| 2 | 基準日時点の出来高（既済部分）を確定 | 出来高数量 |
| 3 | 残工事数量 ＝ 当初数量 − 出来高数量 | 工種・細別ごと |
| 4 | 変動前残工事代金額 **P1** ＝ 残工事数量 × 旧単価 | 当初契約の単価 |
| 5 | 変動後残工事代金額 **P2** ＝ 残工事数量 × 新単価 | 基準日時点の最新単価 |
| 6 | 諸経費（共通仮設費・現場管理費・一般管理費）を率で再計算 | P1・P2それぞれで |
| 7 | スライド差額 ＝ P2 − P1 | |
| 8 | 受注者負担額 ＝ 請負代金額 × 1/100 | |
| 9 | **変更額 ＝ スライド差額 − 受注者負担額** | 正の場合のみ増額 |
| 10 | 変更後請負代金額 ＝ 現契約額 ＋ 変更額 | |

### 計算式（VBAに実装する形）

```
残数量(i)     = 当初数量(i) - 出来高数量(i)
変動前金額(i) = 残数量(i) * 旧単価(i)
変動後金額(i) = 残数量(i) * 新単価(i)

P1 = Σ変動前金額 + 諸経費(旧)
P2 = Σ変動後金額 + 諸経費(新)

スライド差額   = P2 - P1
受注者負担額   = 請負代金額 * 0.01      ' 円未満切り捨て？切り上げ？→ 要確認
変更額         = IIf(スライド差額 - 受注者負担額 > 0, スライド差額 - 受注者負担額, 0)
変更後請負代金額 = 請負代金額 + 変更額
```

## 3. 設計書として出力する帳票（想定）

| シート名 | 内容 |
|---|---|
| 表紙 | 工事名・工期・請負代金額・基準日・変更後請負代金額 |
| 総括表 | P1 / P2 / 差額 / 受注者負担額 / 変更額 の一覧 |
| 残工事数量計算書 | 当初数量 − 出来高数量 ＝ 残数量（工種・細別別） |
| 変動前内訳書 | 旧単価での内訳 |
| 変動後内訳書 | 新単価での内訳 |
| 差額対比表 | 変動前・変動後を左右に並べて差額表示 |
