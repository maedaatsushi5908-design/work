# 特殊集計区分一覧表CSVから処分費・管材費を自動入力する

## なぜできるのか

経費計算シート（`203_経費計算シート（試し) 新工種.xlsx`）の中に、こう書かれています。

> 特殊集計区分（水道）＝水道工事における管財費
> 特殊集計区分（処分）＝直工内の処分費等

つまり **処分費と管材費を仕分けている仕組みが、積算システムの「特殊集計区分」そのもの** です。
一覧表CSVを読めば、スライド計算表の

| 列 | 項目 | 元になる特殊集計区分 |
|:---:|---|---|
| **O** | 処分費〇 | 特殊集計区分（処分） |
| **P** | 管材費〇 | 特殊集計区分（水道） |
| **AA** | 処分費額（全数量分） | その行の金額 |

を手入力せずに埋められます。これまで一番手間だった3つが消えます。

---

## 使い方

### 1. 構造チェック（初回だけ）

```
Alt+F8 →「特殊集計区分CSV構造チェック」
```

`_特殊集計CSV構造` シートに、CSVの列の並びと各行の扱いが出ます。
**金額・数量・単価は「（数値）」に置き換わるので、このシートはそのまま送れます。**

見るところは2つです。

- シート上部の「読み取った並び：」が合っているか
- B列「行の扱い」が `明細` / `区分の見出し` を正しく分けているか

### 2. 取込

```
Alt+F8 →「特殊集計区分CSV取込」
```

`_特殊集計取込結果` シートに結果が出ます。

| 列 | 内容 |
|:---:|---|
| A | CSVの行番号 |
| B | 効いていた特殊集計区分 |
| C | 判定（処分費／管材費） |
| D〜G | コード・名称・規格・単位 |
| H | CSVの数量（計算表と違うと黄色） |
| I | CSVの金額 |
| J | スライド計算表の行番号 |
| K | 何をしたか |

最後に **「計算表に同じ明細が見つからなかったCSV行」** が赤字で並びます。
ここが0行なら全部入っています。

---

## 突合のしかた

**コード｜名称｜規格｜単位** をキーにします（旧単価CSVと新単価CSVの突合と同じ作り方です）。
全角・半角と空白は無視します。

同じキーの行が複数あるときは、**CSVと計算表の並びが同じ前提で、上から順に1行ずつ**
対応させます。たとえば `S8712 ＧＸ形直管 本 継手材含む` が2行あれば、
CSVの1行目を計算表の1行目、2行目を2行目に当てます。

---

## 列の並びの読み取り

次の順に読みます。

1. **見出し行をさがす**（先頭20行まで）
   `特殊集計区分` `単価コード` `名称` `単位` `規格` `数量` `金額` などの語が
   3つ以上ある行を見出しとみなし、その語で列を決めます
2. **区分の列を中身から当てる**
   `処分` `水道` `管材` `管財` `区分外` を含むセルがいちばん多い列
3. **区分が「見出しとして立っている」かを見る**
   区分のセルだけが入っていて他が空の行が多ければ、**区分を下の行へ引き継ぐ**グループ表とみなします
4. **見出しが無ければ、残りの列を中身から当てる**
   - 13列以上で1列目がコード・2列目が名称・3列目が単位に見えるなら、スライド用csvと同じ並びとみなします
   - そうでなければ「コードらしい列」「単位らしい列」「文字がいちばん多い列（＝名称）」
     「名称より右の文字列の列（＝規格1・規格2）」「数値の列を左から 数量・単価・金額」の順に決めます
5. **設定シートの「特殊集計CSV列指定」を最後にかぶせる**

これで次の4つの体裁はそのまま読めることを確認しています。

| 体裁 | 例 |
|---|---|
| 見出しあり・1行ごとに区分 | `特殊集計区分,単価コード,名称,単位,規格1,規格2,数量,金額` |
| グループ表・区分が見出し行（データは次の列から） | `特殊集計区分(処分)` の下に `,S8712,ＧＸ形直管,本,…` |
| グループ表・区分とコードが同じ列 | `特殊集計区分(処分)` の下に `S8712,ＧＸ形直管,本,…` |
| 見出しなし・スライド用csvと同じ13列＋区分 | `S8712,ＧＸ形直管,本,…,特殊集計区分(水道)` |

## うまく入らないとき

### 列の並びが違うと言われる／何も入らない

設定シートの **「特殊集計CSV列指定」** に列を書けば、自動の読み取りより優先されます。

```
区分=14,コード=1,名称=2,単位=3,規格1=4,規格2=5,金額=11
```

列はA,B,…の記号でも書けます（`区分=N,コード=A,名称=B`）。
`_特殊集計CSV構造` シートの見出しに「第1列」「第2列」…と出ているので、それを見て書いてください。

### 区分の名前が違う

設定シートの **「処分費の区分名」** と **「管材費の区分名」** に、
区分名に含まれる文字をカンマ区切りで書きます。

| 設定 | 初期値 |
|---|---|
| 処分費の区分名 | `処分` |
| 管材費の区分名 | `水道,管材,管財` |

`区分外` を含む区分名は、どちらにも入れません。

### 「計算表に同じ明細が見つからなかった」が多い

一覧表が **代価表（G・V コード）の中身まで下りた明細** を並べている場合に起こります。
たとえば計算表には `V1001 ／殻運搬処理` という1行しか無いのに、
一覧表には その代価の中の `処分費` の行が載っている、という状態です。

この場合はキーが合わないので自動では入りません。結果シートの赤字の行を見て、
対応する計算表の行（`V1001 ／殻運搬処理` など）に手で `〇` と金額を入れてください。

**この状態かどうかは構造チェックの結果を見れば分かります。**
`_特殊集計CSV構造` シートを送ってもらえれば、代価表をたどって突合する処理を足せます。

### 「数量が計算表と違います」と出る

CSVの数量と計算表のK列（全体数量）が合っていない行です。H列が黄色になります。
AA列に入れた金額が「全数量に対する金額」になっていない可能性があるので、
その行だけは金額を確かめてください。

## 設定シートの項目

| 項目 | 初期値 | 意味 |
|---|---|---|
| 特殊集計区分CSVパス | （空） | 空欄なら実行時にファイルを選びます |
| 特殊集計CSV列指定 | `自動` | 列の並びを手で決めたいとき |
| 処分費の区分名 | `処分` | この文字を含む区分をO列の〇に |
| 管材費の区分名 | `水道,管材,管財` | この文字を含む区分をP列の〇に |
| 特殊集計CSVから処分費額も入れる | `する` | `しない` にすると〇だけ入れて金額は入れません |

---

## 入れないもの

- **スクラップ**には処分費の〇を付けません。
  スクラップは売却して受注者の益になるもので、処分費（払って捨てるもの）とは逆向きです。
  ㉒スクラップとして別に扱います（1000円単位で切り捨て）。
- 特殊集計区分外の行。
