# 特殊集計区分一覧表CSVから処分費・管材費を自動入力する

## なぜできるのか

経費計算シート（`203_経費計算シート（試し) 新工種.xlsx`）の中に、こう書かれています。

> 特殊集計区分（水道）＝水道工事における管財費
> 特殊集計区分（処分）＝直工内の処分費等

つまり **処分費と管材費を仕分けている仕組みが、積算システムの「特殊集計区分」そのもの** です。
一覧表CSVを読めば、スライド計算表の

| 列 | 項目 | 元になる特殊集計区分 |
|:---:|---|---|
| **O** | 処分費〇 | 特殊集計区分（処分）＝`直工内の処分費等` |
| **P** | 管材費〇 | 特殊集計区分（水道）＝`水道工事における管財費` |
| **AA** | 処分費額（スライド前） | **スライド前**の一覧表の金額 |
| **AB** | 処分費額（スライド後） | **スライド後**の一覧表の金額 |

を手入力せずに埋められます。これまで一番手間だった4つが消えます。

**一覧表はスライド前・スライド後の2本読みます。** 単価適用日を変えて2回出力してください
（スライド用csvを2本出すのと同じやり方です）。後の一覧表が無ければキャンセルすれば、
AB列は空のままになり、計算式はAA列の額を使います（処分費は据置が多いのでそれで足ります）。

---

## 一覧表CSVの中身（実物）

`infla-slide/input/特殊集計区分一覧(インフレ前).Csv`（お金を抜いたもの）

見出し行が1行あり、8列です。

| 列 | 見出し | 中身の例 | 使い方 |
|:---:|---|---|---|
| 1 | 基礎単価コード | `T0172` | 表示用 |
| 2 | 名称 | `残土処分費（前田道路）` | 表示用 |
| 3 | **金額** | （お金なので実物では空） | **→ AA列** |
| 4 | 集計区分 | `3` | 番号なので使いません |
| 5 | **集計区分名称** | `直工内の処分費等` | **→ 処分費／管材費の判定** |
| 6 | **代価表等コード番号** | `―` / `G0001` | **→ 内訳の行を特定する** |
| 7 | **親施工単価コード番号** | `V1001` `V0011` … | **→ 同じ（代価表が `―` のとき）** |
| 8 | 親施工数量 | `20` `542` `5` | 同じコードが複数あるときの絞り込み |

### 大事な点

**この一覧表は「内訳の明細」ではなく「代価表の中の基礎単価」を並べたものです。**

たとえば内訳には `V1001 ／殻運搬処理` という1行しかありませんが、
一覧表にはその代価の中にある `T0172 残土処分費（前田道路）` が載っています。
だから **名称や規格では突合できません**。代わりに

- 代価表等コード番号が `―` → 内訳の **親施工単価コード番号** の行
- 代価表等コード番号が `G0001` → 内訳の **`G0001`** の行

をたどります。

実物で確かめたところ、**親施工数量が内訳の数量とぴったり一致**していました。

| CSV行 | 基礎単価 | 代価表 | 親施工単価 | 親施工数量 | 内訳の行 | 内訳の数量 |
|---:|---|---|---|---:|---|---:|
| 2 | T0172 | ― | V1001 | 20 | `V1001 ／殻運搬処理` | 20 ✓ |
| 3 | T0172 | G0001 | V0011 | 5 | `G0001 ／再掘削工` | 1 |
| 4 | T0172 | G0001 | V0013 | 0.1 | 同上（**行3と合算**） | 1 |
| 5 | T0210 | ― | V0002 | 230 | `V0002 ／土砂運搬処理` | 230 ✓ |
| 6 | F1006 | G0012 | F1006 | 17.67 | `G0012 ／廃プラスチック運搬処分` | 1 |
| 7 | T0172 | ― | V0011 | 542 | `V0011 ／殻運搬処理` | 542 ✓ |
| 8 | T0231 | ― | V0005 | 310 | `V0005 ／廃路盤材運搬処理` | 310 ✓ |
| 9 | T0210 | ― | V0003 | 3 | `V0003 ／土砂運搬処理` | 3 ✓ |

**8行 → 7つのまとまり → 内訳の7行に全部当たりました（取りこぼし0）。**
行3と行4のように同じ内訳の行に当たる行が複数あるときは、**金額を合算**します。

末尾の `計` の行は、集計区分名称が空なので自動的に除かれます。

## 使い方

### 1. 構造チェック（体裁が変わったときだけ）

```
Alt+F8 →「特殊集計区分CSV構造チェック」
```

`_特殊集計CSV構造` シートに、CSVの列の並びと各行の扱いが出ます。
**金額・数量・単価は「（数値）」に置き換わるので、このシートはそのまま送れます。**

上の実物の体裁なら、こう読み取られます。

```
区分=4列／区分名称=5列／コード=1列／名称=2列／金額=3列／
代価表コード=6列／親コード=7列／親数量=8列
見出し行=1／区分の引き継ぎ=しない／突合=親コード（代価表・親施工単価）
```

### 2. 取込

```
Alt+F8 →「特殊集計区分CSV取込」
```

1. **【スライド前】**の一覧表CSVを選ぶ
2. **【スライド後】**の一覧表CSVを選ぶ
   - 後の一覧表が無ければ**キャンセル**。AB列は空のままになり、計算式はAA列の額を使います
3. 「いま入っている〇を消してから入れ直すか」を聞かれます
   - 初回は［はい］。手で直したあとに取り込み直すときも［はい］が安全です
4. `_特殊集計取込結果` シートに結果が出ます

設定シートに2本のパスを書いておけば、ファイル選択は省略されます。

| 列 | 内容 |
|:---:|---|
| A | スライド計算表の行番号 |
| B | 突合に使ったコード |
| C | 当て方（代価表／親施工単価／基礎単価） |
| D | 計算表の名称 |
| E | 集計区分名称 |
| F | 判定（処分費／管材費） |
| G | 処分費等の名称（合算したときは `／` でつなぎます） |
| H | 前 件数 |
| I | 前 金額 → AA列に入った額 |
| J | 後 件数 |
| K | 後 金額 → AB列に入った額 |
| L | 結果・注意 |

その下に **「計算表に突合先が見つからなかったCSV行」** が赤字で並びます。
**さがしたコードがそのまま書いてある**ので、そのコードがスライド計算表のA列にあるか
確かめてください（無ければ、そのCSVは別の工事のものか、代価表が深く入れ子になっています）。
ここが0件なら全部入っています。

## 突合のしかた

**計算表の明細行を主役にして、一覧表の行を寄せ集める方式**です（1件ずつ消し込む方式だと、
同じコードの明細が計算表に1行しか無いのに一覧表側が複数行あるぶんが残ってしまうため）。

### 1. 内訳の行をコードでたどる

一覧表の1行につき、次の順にコードをさがします。**最初に計算表のA列で見つかったものを使います。**

| 順 | さがすコード | 備考 |
|:---:|---|---|
| 1 | `代価表等コード番号` | 内訳に出てくる代価表のコード。これが本筋 |
| 2 | `親施工単価コード番号` | 代価表が `―` のとき／1が計算表に無いとき |
| 3 | `基礎単価コード` | 1と2が計算表に無いときの最後の手段 |

2や3で当てたときは、結果シートの「当て方」と「結果・注意」に出ます。

### 2. 同じコードの明細が複数あるときの絞り込み

| 順 | 手がかり |
|:---:|---|
| 1 | **名称が一致する行**（基礎単価がそのまま内訳に出ている場合） |
| 2 | **親施工数量が計算表のK列（全体数量）と一致する行** |
| 3 | 先頭の行（このときは「要確認」と出ます） |

**同じコードの明細が計算表に1行しか無いときは、数量を見ずにその行に入れます。**
そのため「使用系列」が当初でも変更でも、取りこぼしません。

### 3. 金額を合算する

同じ計算表の行に当たった一覧表の行は、**金額を合算**してAA列（前）／AB列（後）に入れます。
一覧表の行が何件まとまったかは結果シートの「前 件数」「後 件数」に出ます。

## 列の並びの読み取り

次の順に読みます。

1. **見出し行をさがす**（先頭20行まで）
   `集計区分` `集計区分名称` `基礎単価コード` `名称` `金額` `代価表等コード番号`
   `親施工単価コード番号` `親施工数量` などの語が3つ以上ある行を見出しとみなします
   - `集計区分` は番号、`集計区分名称` が名前なので、**判定には名称の列**を使います
2. **区分の列を中身から当てる**（見出しが無いとき）
   `処分` `水道` `管材` `管財` `区分外` を含むセルがいちばん多い列
3. **区分が「見出しとして立っている」かを見る**
   区分のセルだけが入っていて他が空の行が多ければ、**区分を下の行へ引き継ぐ**グループ表とみなします
4. **見出しが無ければ、残りの列を中身から当てる**
   「コードらしい列」「単位らしい列」「文字がいちばん多い列（＝名称）」
   「名称より右の文字列の列（＝規格1・規格2）」「数値の列を左から 数量・単価・金額」の順に決めます
5. **設定シートの「特殊集計CSV列指定」を最後にかぶせる**

実物のほか、次の体裁でも読めることを確認しています。
`代価表等コード番号` や `親施工単価コード番号` が無い体裁では、**基礎単価コード＋名称**で突合します。

| 体裁 |
|---|
| 実物（見出しあり・代価表／親施工単価コード番号あり） |
| 見出しあり・1行ごとに区分 |
| グループ表・区分が見出し行（データは次の列から） |
| グループ表・区分とコードが同じ列 |
| 見出しなし・区分の列だけが後ろにある |

## うまく入らないとき

### 列の並びが違うと言われる／何も入らない

設定シートの **「特殊集計CSV列指定」** に列を書けば、自動の読み取りより優先されます。
実物の体裁を手で書くとこうなります。

```
区分名称=5,コード=1,名称=2,金額=3,代価表コード=6,親コード=7,親数量=8
```

書ける項目は `区分` `区分名称` `コード` `名称` `単位` `規格1` `規格2` `数量` `単価` `金額`
`摘要` `代価表コード` `親コード` `親数量` です（`集計区分名称` `代価表等コード番号`
`親施工単価コード番号` `親施工数量` という書き方もできます）。

列はA,B,…の記号でも書けます。
`_特殊集計CSV構造` シートの見出しに「第1列」「第2列」…と出ているので、それを見て書いてください。

### 区分の名前が違う

設定シートの **「処分費の区分名」** と **「管材費の区分名」** に、
区分名に含まれる文字をカンマ区切りで書きます。

| 設定 | 初期値 | 実物での当たり方 |
|---|---|---|
| 処分費の区分名 | `処分` | `直工内の処分費等` に当たります |
| 管材費の区分名 | `水道,管材,管財` | `水道工事における管財費` に当たります |

`区分外` を含む区分名は、どちらにも入れません。

### 「突合先が見つかりませんでした」が出る

結果シートの赤字の行に **「さがしたコード」** が出ています。たとえば
`G9999 → V0013 → T0172` なら、この3つのコードがどれもスライド計算表のA列に無かった、
ということです。心当たりは次の3つです。

1. **一覧表と計算表が別の工事のもの**　…　いちばん多い原因です。
   スライド用csvと同じ設計書から一覧表を出し直してください
2. **代価表の中にさらに代価表が入っている**　…　内訳までたどれません。
   対応する内訳の行に手で `〇` と金額を入れてください
3. **スライド前と後で設計が変わって、その工種が無くなった**　…　無視して構いません

### 「同じコードの明細が○行あります。先頭の行に入れました（要確認）」が出る

同じ施工単価コードが内訳に複数あり、名称でも親施工数量でも決められなかった行です。
C列が黄色になります。A列の行番号を見て、入った先が正しいか確かめてください。
違っていれば、その行の〇と金額を手で移してください。

### 「★CSVに金額が無いので、AA列に処分費の額を手で入れてください」と赤字で出る

一覧表の金額の列が空だったときです。**この行は必ず手入力してください。**
AA列が空のままだと、**その内訳行の金額を全額 処分費として扱ってしまい、過大になります**
（たとえば `／殻運搬処理` なら運搬費まで処分費に入ってしまいます）。

## 設定シートの項目

| 項目 | 初期値 | 意味 |
|---|---|---|
| 特殊集計区分CSVパス（スライド前） | （空） | 空欄なら実行時にファイルを選びます |
| 特殊集計区分CSVパス（スライド後） | （空） | 同じ。無ければ実行時にキャンセルすればAB列は空のまま |
| 特殊集計CSV列指定 | `自動` | 列の並びを手で決めたいとき |
| 処分費の区分名 | `処分` | この文字を含む区分をO列の〇に |
| 管材費の区分名 | `水道,管材,管財` | この文字を含む区分をP列の〇に |
| 特殊集計CSVから処分費額も入れる | `する` | `しない` にすると〇だけ入れて金額は入れません |

## 入れないもの

- **スクラップ**には処分費の〇を付けません。
  スクラップは売却して受注者の益になるもので、処分費（払って捨てるもの）とは逆向きです。
  ㉒スクラップとして別に扱います（1000円単位で切り捨て）。
  一覧表側の名称と計算表側の名称の両方を見て判定します。
- 集計区分名称が空の行（末尾の `計` の行など）。
- `区分外` を含む区分の行。
