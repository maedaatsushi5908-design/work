# 経費計算シート と スライド調書（様式4-2号）の解析

`203_経費計算シート（試し) 新工種.xlsx` を解析して、VBAで再現した内容です。

## 1. 様式4-2号（最終出力）の算式

| 記号 | 内容 | 出所 |
|---|---|---|
| ① | 設計額（税込） | 経費計算シート A列 ㉔工事費 |
| ② | 工事価格（税抜） | 経費計算シート A列 ㉑'（スクラップ込み） |
| ③ | 請負代金額（税込） | ＝ ① × 請負率 |
| ④ | 請負工事価格（税抜） | ＝ ③ × 10/11 |
| ⑤ | 出来高 | 経費計算シート G列 ㉑' |
| ⑥ | 出来高（請負率考慮） | ＝ ⑤ × ③/① |
| ⑦ | 残工事（変動前・設計ベース） | ＝ ② − ⑤ |
| ⑧ | 残工事（変動後・設計ベース） | 経費計算シート F列 ㉑' |
| **P1'** | 残工事（変動前・請負ベース） | ＝ ④ − ⑥ |
| **P2'** | 残工事（変動後・請負ベース） | ＝ ⑧ × ③/① |
| ⑨ | 新工種抜き（請負ベース） | 経費計算シート H列 ㉑' × ③/① |
| ⑩ | 新工種抜き 出来高（請負ベース） | 経費計算シート I列 ㉑' × ③/① |
| **P1''** | **新工種抜きの残工事（請負ベース）** | ＝ ⑨ − ⑩ |
| **S'** | **スライド額** | 増額：`P2' − P1' − P1'' × 1%`<br>減額：`P2' − P1' + P1'' × 1%` |

**受注者負担1%の母数は P1'（残工事）ではなく P1''（新工種を抜いた残工事）です。**
基準日以降に追加された新工種は、受注者が当初から見込めなかった分なので負担の母数から外します。

> 元ファイルの G16 は `=F16-E16-(E20*1/100)` と符号が固定でした。
> すぐ上の G15 のラベルは増額／減額で符号を出し分けているので、
> VBA版では `=IF(E16>F16, F16-E16+(E20*1/100), F16-E16-(E20*1/100))` として符号を切り替えています。

## 2. 経費計算シートの9系列

| 記号 | 名称 | 素材（スライド計算表の列） | 経費率 |
|:---:|---|---|---|
| A | 変更設計書（全体） | R スライド前・全体 | 旧（自前） |
| B | 変更設計書 残工事 | T スライド前・残工事 | ―（素材のみ） |
| C | 単価更新設計書 残工事 | V スライド後・残工事 | ―（素材のみ） |
| D | 変更設計書 出来高 | S スライド前・出来形 | ―（素材のみ） |
| E | スライド設計書（全体・新単価） | U スライド後・全体 | 新（自前） |
| F | 単価更新設計書 残工事【経費計算】 | V スライド後・残工事 | E列の新経費率 |
| G | 変更設計書 出来高【経費計算】 | S スライド前・出来形 | A列の旧経費率 |
| H | 変更設計書 新工種抜き（全体） | R（新工種〇の行を除く） | 新工種抜き（自前） |
| I | 変更設計書 新工種抜き 出来高 | S（新工種〇の行を除く） | H列の率 |

**様式4-2号が参照するのは A・F・G・H・I の5系列**です。B・C・D は素材を確認するための列で、
経費計算はしません（元ファイルと同じ扱い）。

## 3. 経費の算式

```
③率計算の対象外費 = MAX(0, ② − ROUNDDOWN((① − ①'/2) × 3%, 0))
⑥共通仮設費対象額 = ① − ③ − ①'/2
⑦'共通仮設費率分  = ROUNDDOWN(⑥ × ⑦, -3)
⑧共通仮設費【合計】= ④ + ④' + ⑤ + ⑦'
⑨純工事費        = ① + ⑧
⑩現場管理費対象額  = ⑨ − ③ − ①'/2
⑫現場管理費      = ROUNDDOWN(⑩ × ⑪, -3)
⑬工事原価        = ⑨ + ⑫
⑭一般管理費対象額  = ⑬ − ③            ※①'は引かない
⑮'一般管理費率分  = ⑭ × ⑮
⑰一般管理費（端数整理前）= ⑮' + ⑯契約保証費
⑱工事価格（端数整理前）  = ⑬ + ⑰
⑲端数整理        = ⑱ − ROUNDDOWN(⑱, -3)
⑳一般管理費（端数整理後）= ⑰ − ⑲
㉑工事価格        = ⑬ + ⑳
㉑'工事価格（スクラップ込み）= ㉑ + ㉒
㉓消費税相当額    = (㉑ + ㉒) × 10%
㉔工事費          = ㉑ + ㉒ + ㉓
```

### ③の算式は実データで検算済み

元ファイルの6系列すべてで一致しました。

| 系列 | ① | ①' | ② | ③（実値） | 計算値 |
|---|---:|---:|---:|---:|---:|
| A 変更設計書全体 | 159,813,308 | 50,535,000 | 5,772,498 | 1,736,124 | 一致 |
| B 変更設計書残工事 | 101,128,573 | 15,835,000 | 5,517,438 | 2,721,106 | 一致 |
| C 単価更新残工事 | 104,093,462 | 16,660,000 | 5,526,273 | 2,653,370 | 一致 |
| E スライド設計書 | 162,778,197 | 51,360,000 | 5,781,333 | 1,668,388 | 一致 |
| H 新工種抜き | 152,213,308 | 42,935,000 | 5,772,498 | 1,850,124 | 一致 |

端数処理は `ROUNDDOWN((① − ①'/2) × 3%, 0)` で、切り捨てを入れないと1円ずれます。

## 4. 経費率の扱い

元ファイルでは経費率（⑦⑪⑮）は**積算システムの計算結果から手で引用**していました。
VBA版では**神戸市の率式で自動計算した値を初期値として入れ、上書きできる**ようにしています。

```
共通仮設費率 = ROUND(ROUND(ROUND(1228.3 × ⑥ ^ (-0.2614), 2) × 1.2, 2) × 1.04, 2) / 100
現場管理費率 = ROUND(ROUND(ROUND(458.2 × ⑩ ^ (-0.1508), 2) × 1.1, 2) × 1.06, 2) / 100
一般管理費率 = ROUND(-5.48972 × LOG10(⑭) + 59.4977, 2) / 100
```

係数は設定シートで変更できます（工種区分で変わるため）。
積算システムの値を使う場合は、経費計算シートの率セルを直接上書きしてください。

自前の率を持つのは A・E・H の3列だけで、F は E を、G は A を、I は H を参照します。
**つまり、積算システムで率を取るとしても3回で済みます（元は設計書(1)〜(9)の9系統）。**

## 5. SUMIFS ではなく SUMPRODUCT を使っている理由

明細行だけを集計する条件に `SUMIFS(範囲, 単価列, "<>")` を使ったところ、
数式エンジンによって「空白でない」の解釈が逆転する挙動を確認しました。
そのため集計はすべて `SUMPRODUCT` で書いています。

```
①直接工事費 = SUMPRODUCT((単価列<>"") * (金額列))
新工種抜き   = SUMPRODUCT((単価列<>"") * (新工種列<>"〇") * (金額列))
```

階層行は単価が空なので自動的に除外され、二重計上になりません。
