# 使い方（手順書）

エスティマのCSVから、**スライド計算表**（明細＋経費計算）と
**スライド調書（様式4-2号）** を作ります。

- 入力：スライド用csv **2本**（旧単価／新単価）＋（任意）特殊集計区分一覧表csv **2本**
- 手入力：**出来形数量だけ**（＋調書の請負代金額）
- 出力：`スライド調書（様式4-2号）` の **G16 ＝ スライド額 S'**

## 1. 準備（最初の1回だけ）

### 1-1. マクロ有効ブックを作る

1. Excelを起動して新規ブックを作る
2. 「名前を付けて保存」→ ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** にして保存

> 通常の `.xlsx` で保存するとマクロが消えます。

### 1-2. VBAを貼り付ける

**貼り付けるファイルは1つだけ**です。下のリンクを開きます。

| 版 | リンク |
|---|---|
| **新工種を考慮する（通常）** | [ALL_IN_ONE.bas](https://github.com/maedaatsushi5908-design/work/blob/claude/intelligent-feynman-5jyidy/infla-slide/vba/ALL_IN_ONE.bas) |
| 新工種を考慮しない | [ALL_IN_ONE_新工種なし.bas](https://github.com/maedaatsushi5908-design/work/blob/claude/intelligent-feynman-5jyidy/infla-slide/vba/ALL_IN_ONE_%E6%96%B0%E5%B7%A5%E7%A8%AE%E3%81%AA%E3%81%97.bas) |

中身は同じで、設定シートの「新工種を考慮する」の初期値だけが違います。
どちらを貼っても、あとから設定シートで切り替えられます。

#### コピーのしかた

リンクを開くと、コードが並んだ**枠**が出ます。枠の**右上**のボタンを使います。

```
                                      ┌────────────────────────┐
                                      │ Raw │ ⧉ │ ↓ │ ✏ │ ⋯ │
                                      └────────────────────────┘
                                        ↑     ↑
                                文字だけ表示   ここを押すと全部コピー
```

- **`⧉`（四角が2枚重なったアイコン）を押すとファイル全体がコピーされます。** これが一番早いです
- `Raw` を押して文字だけのページにしてから `Ctrl+A` → `Ctrl+C` でも同じです

#### 貼り付け

1. Excelで `Alt+F11` → VBE（Visual Basic Editor）が開く
2. メニューの **「挿入」→「標準モジュール」**
3. 右側の白い画面をクリックして `Ctrl+V`
4. `Alt+F11` でExcelに戻る

**モジュール名の変更も参照設定の追加も要りません。**

## 2. 毎回の手順

### 手順1　エスティマからCSVを出す

```
機能 → CSV連携 → 抽出指示ファイル「スライド用csv出力」→ csv抽出
```

**単価適用日を変えて2回**出力します。

| | 単価適用日 | ファイル名の例 |
|---|---|---|
| 旧単価CSV | 当初 | `〇〇工事_旧単価.csv` |
| 新単価CSV | スライド基準日 | `〇〇工事_新単価.csv` |

数量・工種構成は同じで、単価だけが違うCSVになります。

> **特殊集計区分一覧表のCSVも出せる場合**は、同じく単価適用日を変えて2本出しておくと、
> 処分費・管材費の〇と金額が自動で入ります（手順4）。

### 手順2　設定シートを作る

```
Alt+F8 →「設定シート作成」→ 実行
```

「設定」シートができます。**黄色いセル**に入力します。最低限いるのはこの2つです。

| 項目 | 入れるもの |
|---|---|
| **請負代金額** | 税込。様式4-2号の請負率の計算に使います |
| **基準日** | インフレスライドの請求日 |

残りは既定のままで動きます。全項目は [6章](#6-設定シートの全項目) にあります。

> 経費率の係数は道路改良工事・公園工事等の値が入っています。
> 違う工種区分なら、ここを直すか、あとで経費計算部の率セルを直接上書きしてください。

### 手順3　スライド計算表を作る

```
Alt+F8 →「スライド計算表作成」→ 実行
```

1. 「【旧単価】…」→ 旧単価CSVを選ぶ
2. 「【新単価】…」→ 新単価CSVを選ぶ

できるシートはこれだけです。

| シート | 中身 |
|---|---|
| **スライド計算表** | 明細部＋経費計算部（①〜㉔を7系列） |
| **スライド調書（様式4-2号）** | 計算表からリンク。**G16がスライド額** |
| `_単価表`（非表示） | 代価表の中身の索引。手順4で使います |

> 実行後にメッセージが出ます。**★が付いた件数があれば必ず確認してください**
> （新単価が見つからなかった行など。[7章](#7-困ったとき)）。

### 手順4　特殊集計区分CSVを取り込む（任意・あると楽）

```
Alt+F8 →「特殊集計区分CSV取込」→ 実行
```

1. **【スライド前】**の一覧表CSVを選ぶ → AA列（処分費額 前）に入ります
2. **【スライド後】**の一覧表CSVを選ぶ → AB列（処分費額 後）に入ります
   - 無ければ**キャンセル**。AB列は空のままで、計算式はAA列の額を使います
3. 「いま入っている〇を消してから入れ直すか」→ 初回は **［はい］**
4. `_特殊集計取込結果` シートに結果が出ます

| 集計区分名称 | 入るところ |
|---|---|
| `直工内の処分費等` | O列に `〇`、AA列（前）・AB列（後）に金額 |
| `水道工事における管財費` | P列に `〇` |
| 特殊集計区分外 | 何も入れません |

- **スクラップには処分費の〇を付けません**（売却益なので処分費ではありません。㉒で別に扱います）
- **金額の列が空だった行は赤字で出ます。AA列を必ず手入力してください**
  （空のままだとその行の金額を全額 処分費として扱い、過大になります）
- **突合できなかった行には、さがしたコードがそのまま出ます。**
  まず一覧表とスライド用csvが同じ設計書から出ているか確かめてください
- 先に **［特殊集計区分CSV構造チェック］** を実行すると、列の並びだけを
  `_特殊集計CSV構造` に書き出します（金額・数量・単価は「（数値）」に置き換わるのでそのまま送れます）
- 詳しくは [特殊集計区分CSV.md](特殊集計区分CSV.md)

### 手順5　出来形数量を入れる

スライド計算表の **L列（数量・出来形）** に、出来高検査の数量を入れます。
**明細行だけ**でOK。階層行（工種・種別・細別）は自動で集計されます。

M列（残工事）は `=K-L` で自動です。

### 手順6　調書の請負代金額を入れる

スライド調書の **C14（請負代金額・税込）** だけが手入力です
（設定シートの値が初期値で入っています）。

請負率(%)・請負工事価格（税抜）・消費税相当額は、ここから**計算で出ます**。

### 手順7　できあがり

**スライド調書の G16 がスライド額 S'** です。E3に「増額スライド／減額スライド」が出ます。

調書は計算表からリンクしているので、**出来形や〇を直すと調書も自動で追従します。**

## 3. 手入力するところ

黄色いセルが手入力です。

### スライド計算表・明細部

| 列 | 項目 | 入れるもの |
|:---:|---|---|
| **L** | 数量（出来形） | **必須。**出来高検査の数量 |
| **O** | 処分費〇 | 処分費の行に `〇`。※手順4で自動入力できます |
| **P** | 管材費〇 | 水道工事の管材費の行に `〇`。※手順4で自動入力できます |
| **Q** | 新工種〇 | 基準日以降に追加された新工種の行に `〇`。当初数量0・変更数量ありの明細には**自動で入ります**。基準日より前の変更なら外してください |
| **AA** | 処分費額（スライド前） | **全数量に対する処分費の総額**。空欄ならその行の金額を全額 処分費として扱います。※手順4で自動入力できます |
| **AB** | 処分費額（スライド後） | 空欄ならAA列の値を使います。処分費は据置が多いのでAA列だけで足ります |

> **O列（処分費〇）にスクラップの行を付けないでください。**
> スクラップは売却して受注者の益になるもので、処分費とは逆向きです。㉒で別に扱います。
>
> **R列は明細部では使いません。** 経費計算部のZコード項目の区分だけに使います。

### スライド計算表・経費計算部（明細のすぐ下）

| 項目 | 入れるもの |
|---|---|
| **Zコード項目の区分（R列）** | 自動で入ります。課の運用と違えば直してください（下記） |
| **⑦⑪⑮ 経費率** | 自動計算した値が入っています。積算システムの値があれば上書きしてください |
| **⑯契約保証費** | **全体の列（S・V・X）だけ**が手入力。出来高・残工事の列は自動です |

率を自前で持つのは **S列（前・全体）・V列（後・全体）・X列（新工種抜き・全体）の3つだけ**です。
T列はS列、W列はV列、Y列はX列の率を参照するので、
**積算システムで率を取る場合でも3回で済みます。**

#### Zコード項目の区分（R列）

諸経費部のZコード項目を1行ずつ並べ、R列に区分を入れています。

| 区分 | 意味 | 自動判定 |
|:---:|---|---|
| **積** | 共通仮設費の積上分（運搬費・準備費・技術管理費など）。④に算入 | `Z0001`〜`Z0039` |
| **原** | ⑬工事原価に加算（工期延長等に伴う増加費用など） | `Z0040`〜`Z0044` |
| **価** | ㉑工事価格に加算（設計委託費など） | `Z0045` 以降 |
| **ス** | スクラップ。㉒に算入（**1000円単位に切捨**） | 名称に「スクラップ」を含む |
| 空欄 | 計算に使わない | 支給品費 |

**課の運用と違う場合はR列を直してください。** 全系列（S〜Y列）に一度に効きます。

### スライド調書（様式4-2号）

| セル | 項目 |
|---|---|
| **C14** | 請負代金額（税込）。**ここだけ手入力** |

## 4. 画面の見方

### スライド計算表の列

```
【明細部】8行目〜（Zコードより前がすべて直接工事費）
A        コード（非表示にしてOK）
B〜F     費目／工事区分／工種／種別／細別   ①②③④のマーカーで階層を表現
G,H      施工単価名称／規格
I,J      単価（スライド前／スライド後）     ← 旧単価CSV／新単価CSV
K,L,M    数量（全体／出来形★／残工事）
N        単位
O,P,Q    処分費〇★／管材費〇★／新工種〇☆
R        区分（経費計算部のZコード項目でだけ使う）★
S,T,U    スライド前（全体／出来形／残工事・検算用）
V,W      スライド後（全体／残工事）
X,Y      新工種抜き（全体／出来形）
Z        摘要
AA,AB    処分費額（全数量分・前★／後★）
AC〜AI   処分費額（7系列）

【経費計算部】明細のすぐ下
①〜③ → Zコード項目を1行ずつ（R列に区分） → ④〜㉔　を S〜Y の7系列で計算

★＝手入力　☆＝自動（修正可）
```

背景色は階層のレベルです。濃い青＝費目、薄い青＝工事区分、以下同様。

### 7系列の意味

| 列 | 内容 | 単価 | 経費率 |
|:---:|---|---|---|
| **S** | スライド前・全体（＝元設計） | 旧 | 自前 |
| **T** | スライド前・出来形（＝出来高） | 旧 | S列の率 |
| U | スライド前・残工事（**検算用**。`S＝T＋U` の確認にだけ使います） | 旧 | 素材のみ |
| **V** | スライド後・全体（＝スライド設計書）**＝T＋W** | 旧＋新 | 自前 |
| **W** | スライド後・残工事 | 新 | V列の率 |
| **X** | 新工種抜き・全体 | 旧 | 自前 |
| **Y** | 新工種抜き・出来形 | 旧 | X列の率 |

- 「新工種を考慮する」を `しない` にすると **X・Y列は出ません**（S〜Wの5系列）
- **様式4-2号が使うのは S・T・W・X・Y の5列**です
- **U列はどこからも使われません。** 経費計算部でも「素材のみ」で④まで、他の系列の率も参照しません

いまどちらのモードかは、**スライド計算表の `K1` セル**と
**スライド調書の `G4` セル**に出ます（考慮しないときは赤字）。

### スライド調書（様式4-2号）

```
P1'  = 請負工事価格 － 出来高（請負率考慮）            … 残工事
P1'' = 新工種抜き   － 新工種抜き出来高（請負率考慮）   … 1%の母数
S'   = P2' － P1' － P1'' × 1%      （増額スライド）
     = P2' － P1' ＋ P1'' × 1%      （減額スライド）

※「新工種を考慮する」を `しない` にした場合は P1'' ＝ P1' になります。
```

## 5. 計算のきまり

### 金額は1円未満切り捨て

`単価 × 数量` はすべて `ROUNDDOWN(…, 0)` です。処分費額を数量比で割り振るときも同じです。

### スライド後は「出来形＝旧単価＋残工事＝新単価」

**V列（スライド後・全体）は「全数量×新単価」ではありません。**
出来高はもう払い終わっているので旧単価のまま、残工事だけ新単価にします。
1行の中で出来形が中途半端な工種は、**その行の中で旧単価と新単価の両方**を使います。

```
単価 1,000→1,100　全数量 10　出来形 4　残工事 6

  T 出来形 ＝ 4 × 1,000 ＝ 4,000    （旧単価。もう払い終わっている）
  W 残工事 ＝ 6 × 1,100 ＝ 6,600    （新単価）
  V 全体   ＝ 4,000 ＋ 6,600 ＝ 10,600
```

全数量×新単価だと 10×1,100＝11,000 になり、
すでに払い終わった4単位分の値上がり（4×100＝400円）まで乗ってしまいます。
AF列（処分費額 後・全体）も同じ考え方で `AD＋AG` です。

### ③率計算の対象外費は按分

全体だけを算式で出し、出来高・残工事は**全体の③を②（処分費等）の比で割り振り**ます。

```
全体        ＝ MAX(0, ② － ROUNDDOWN((① － ①'/2) × 3%, 0))
出来高・残工事 ＝ ROUNDDOWN(全体の③ × その系列の② ÷ 全体の②, 0)
```

**旧単価の系列は旧単価の全体から、新単価の系列は新単価の全体から**按分します（混ざりません）。
系列ごとに算式を当てると出来高＋残工事が全体に一致しないので、按分にしています。

> 設定シートの「③の出来高・残工事」を `系列ごとに計算` にすると、従来の挙動に戻ります。

### ⑯契約保証費は出来高の側に乗せる

契約保証費は請負契約に1回だけ付くので、**出来高に乗せ、残工事は0**にします。
**出来高が0（まだ何も出来ていない）ときだけ、残工事に乗せます。**

| 系列 | 出来高がある場合 | 出来高が0の場合 |
|---|---:|---:|
| S・V・X（全体）**手入力** | 契約保証費 | 契約保証費 |
| T・Y（出来高） | 契約保証費 | **0** |
| W（残工事） | **0** | 契約保証費 |

こうしないとスライド額が契約保証費の分だけ過大になります。
`P1'` は「全体－出来高」の引き算なので両方に入っていると打ち消えますが、
`P2'` は残工事そのものなので残工事に入ったままになるためです。

### 旧CSVと新CSVの突合

2本のCSVの行がそろっていないときは、次の順に試します。

| 順 | 突合のしかた | J列の印 |
|---:|---|---|
| 0 | 全体の行数も並びも同じ → 行の位置 | なし |
| A | 部ごと（単価表部／内訳部）に行数が同じ → その部の行の位置 | なし |
| B | コード＋名称＋規格＋単位 | なし |
| C | コード＋名称＋単位 | **黄** |
| D | コード＋名称 | **黄** |
| E | コードだけ | **黄** |
| — | どれも当たらない → 旧単価を据置 | **赤** |
| — | 新単価が0・旧単価が0でない → 旧単価を据置 | **赤** |

**値上がり0で正しく同じ場合は印が付きません。**
「J列がI列と同じ」を見たとき、正常なのか突合できなかったのか区別できます。

## 6. 設定シートの全項目

### 【工事情報】

| 項目 | 既定 | 意味 |
|---|---|---|
| 工事名 / 工事場所 / 工期（自）（至） | （空） | 任意 |
| **請負代金額** | 0 | 税込。様式4-2号の請負率の算出に使います |
| **基準日** | （空） | インフレスライドの請求日 |
| 発注者 / 受注者 | 神戸市 / （空） | 任意 |

### 【CSV設定】

| 項目 | 既定 | 意味 |
|---|---|---|
| 旧単価CSVパス / 新単価CSVパス | （空） | 空欄なら実行時にダイアログで選択 |
| 文字コード | `Shift_JIS` | 文字化けしたら `UTF-8` |
| 区切り文字 | `,` | |
| 使用系列 | `変更` | `変更`／`当初`。CSVの**①列＝変更設計、②列＝当初設計** |
| **新工種を考慮する** | `する` | `しない` にすると新工種の列・系列を出さず、1%の母数は残工事そのもの |
| 新工種の自動判定 | `する` | 当初数量0・変更数量ありの明細にQ列の〇を自動で付ける |

### 【特殊集計区分CSVの設定】

| 項目 | 既定 | 意味 |
|---|---|---|
| 特殊集計区分CSVパス（スライド前）（スライド後） | （空） | 空欄なら実行時に選択 |
| 特殊集計CSV列指定 | `自動` | 列の並びを手で決めたいとき |
| 処分費の区分名 | `処分` | この文字を含む区分をO列の〇に。カンマ区切りで複数可 |
| 管材費の区分名 | `水道,管材,管財` | 同じくP列の〇に |
| 特殊集計CSVから処分費額も入れる | `する` | `しない` にすると〇だけ入れて金額は入れません |

### 【経費計算の設定】

| 項目 | 既定 | 意味 |
|---|---|---|
| **契約保証費** | 0 | 当初設計時の額。出来高に乗り、残工事は0 |
| 処分費控除率 | 0.03 | ③の全体＝② − ROUNDDOWN((① − ①'/2)×この率, 0) |
| **③の出来高・残工事** | `按分` | `按分`／`系列ごとに計算` |
| 消費税率 | 0.1 | |

### 【経費率の自動計算】

| 項目 | 既定 | 算式 |
|---|---|---|
| 共通仮設費率A / B | 485.4 / -0.2231 | 率(%) = A × 対象額 ^ B |
| 共通仮設費 地域補正 / 週休補正 | 1.5 / 1.01 | |
| 現場管理費率A / B | 202.3 / -0.1034 | 率(%) = A × 対象額 ^ B |
| 現場管理費 地域補正 / 週休補正 | 1.2 / 1.02 | |
| 一般管理費率係数 / 定数 | -4.97802 / 56.92101 | 率(%) = 係数 × LOG10(対象額) + 定数 |

> **古い設定シートを使い回す場合**、`スライド計算表作成` を実行すると
> **足りない設定が赤字で自動追加されます。** 確認してからもう一度実行してください。

## 7. 困ったとき

### 実行できるマクロ

`Alt+F8` で出てくる一覧です。

#### 普段使うもの

| マクロ | いつ使うか |
|---|---|
| `設定シート作成` | 最初の1回。工事が変わったらまた |
| `スライド計算表作成` | 毎回。計算表と調書を作る（メイン） |
| `特殊集計区分CSV取込` | 毎回（任意）。処分費〇・管材費〇・処分費額を自動入力 |

#### 困ったときだけ使うもの（普段は触らなくてよい）

| マクロ | いつ使うか | 何が出るか |
|---|---|---|
| `CSV構造チェック` | **階層がおかしい／直接工事費に入るはずの行が入っていない**とき | `_CSV構造` シートに、CSVの各行をマクロがどう判定したか（費目・工種・明細・Zコードなど）を1行ずつ書き出す |
| `特殊集計区分CSV構造チェック` | **特殊集計区分CSVが取り込めない／取りこぼしが多い**とき | `_特殊集計CSV構造` シートに、CSVの列の並びと各行の扱いを書き出す |
| `テスト用CSV作成` | **貼り付けがうまくいったか試したい**とき。課の方に教えるときの練習用 | サンプルCSVを2本作り、設定シートにパスを入れる。そのまま［スライド計算表作成］を実行できる |

> **`CSV構造チェック` と `特殊集計区分CSV構造チェック` は金額・単価・数量を出しません。**
> 判定結果とコード・名称だけなので、**結果シートをそのままコピーして送れます。**
> 実際にこの2つで、仮設工が直接工事費に入らない不具合と、
> 特殊集計区分CSVの列を読み落としていた不具合を見つけて直しました。

#### この3つは消してもよいか

| マクロ | おすすめ | 理由 |
|---|---|---|
| `CSV構造チェック` | **残す** | 階層がおかしいときの唯一の手がかり。金額が出ないのでそのまま送れる |
| `特殊集計区分CSV構造チェック` | **残す** | 同じ理由。一覧表の体裁が変わったときにも使う |
| `テスト用CSV作成` | **消してもよい** | 実物のCSVがあるので役目はほぼ終わり。練習用として残す価値だけ |

### 症状と対処

| 症状 | 原因と対処 |
|---|---|
| マクロが一覧に出てこない | 貼り付け先が「標準モジュール」か確認。`.xlsm` で保存しているかも確認 |
| **㉑㉒㉓㉔ が `?` になる** | **2026-10-19より前の版の不具合です。** ㉑以降の〇数字は Shift-JIS に無いので、VBEに貼った時点で文字が失われていました。いまは `ChrW()` でコードから作っています。最新の `ALL_IN_ONE.bas` に貼り替えてください |
| 文字化けする | 設定シートの「文字コード」を `UTF-8` にして再実行 |
| 「明細を1行も読み取れませんでした」 | CSVが「スライド用csv出力」の形式か確認。`CSV構造チェック` の結果を送ってください |
| 階層がおかしい | `CSV構造チェック` を実行して結果を送ってください |
| **J列がI列と同じ（色なし）** | **正常です。**突合できていて、単価が動かなかっただけです |
| **J列が赤い**＋摘要に `★新単価なし` `★新単価が0` | 新CSVにその行が見つからなかった（または0だった）ので旧単価を据え置いています。金入設計書と見比べてください |
| **J列が黄色**＋摘要に `★新単価は…で突合` | 規格や単位が2本のCSVで一致せず、ゆるい条件で当てた行です。どの条件で当てたか摘要に出ます |
| 「旧CSVと新CSVで行がずれていた」と出る | 2本のCSVで行がそろっていません。段階的に突合し直すので多くは問題ありませんが、★の件数が多いときは要確認 |
| 仮設材運搬費・技術管理費が積上分に入らない | 経費計算部のZコード項目の行で、R列に `積` と入れてください |
| 共通仮設費が大きすぎる | `Z0040` 以降に `積` が付いていないか確認。付いていると二重計上になります |
| 直接工事費に仮設工が入っていない | Zコードより前の行はすべて直接工事費に入ります。入っていなければ `CSV構造チェック` の結果を送ってください |
| 経費率が課の値と違う | 経費計算部の ⑦⑪⑮ を直接上書きするか、設定シートの係数を変えてください |
| 工事費が金入設計書と合わない | 経費率を積算システムの値で上書き。それでも合わなければ ⑯契約保証費・㉒スクラップ・端数整理を確認 |
| ③の出来高・残工事が元の経費計算シートと違う | 既定を**按分**にしています。元に戻すには設定シートの「③の出来高・残工事」を `系列ごとに計算` に |
| 特殊集計区分CSVが1行も取り込めない | メッセージに読み取った列の並びが出ます。`★` が付いていればその列を読めていないので、「特殊集計CSV列指定」に列を書いてください |
| 「`_単価表` シートが無い」系の取りこぼし | `スライド計算表作成` をやり直すと作られます。古いブックには入っていません |
| 新工種なし版を貼ったのに新工種の列が出る | 古い設定シートに項目が無く既定に戻っていました。`スライド計算表作成` で設定が追加されるので、確認してもう一度実行してください |

### やり直したいとき

`スライド計算表作成` を実行すると、シートは**作り直し**になります。
**手入力した出来形や〇は消えます。** やり直す前にシートをコピーして退避してください。
