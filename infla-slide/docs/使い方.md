# 使い方（手順書）

エスティマのCSV2本から、**スライド計算表 → 経費計算シート → スライド調書（様式4-2号）** を作ります。

---

## 準備（最初の1回だけ）

### 1. マクロ有効ブックを作る

1. Excelを起動して新規ブックを作る
2. 「名前を付けて保存」で、ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** にして保存
   （通常の .xlsx で保存するとマクロが消えます）

### 2. VBAを貼り付ける

**貼り付けるファイルは1つだけです。** 下のリンクを開いてください。

#### 開くリンク

**新工種を考慮する（通常）**

https://github.com/maedaatsushi5908-design/work/blob/claude/intelligent-feynman-5jyidy/infla-slide/vba/ALL_IN_ONE.bas

**新工種を考慮しない**

https://github.com/maedaatsushi5908-design/work/blob/claude/intelligent-feynman-5jyidy/infla-slide/vba/ALL_IN_ONE_新工種なし.bas

中身は同じで、設定シートの「新工種を考慮する」の初期値だけが違います。
どちらを貼っても、**あとから設定シートで切り替えられます**。

> **以前のバージョンで作った「設定」シートを使い回す場合**、
> 「新工種を考慮する」の項目がまだありません。
> その場合は `スライド計算表作成` を実行すると**足りない設定が自動で追加されます**
> （赤字で表示されます）。確認してからもう一度実行してください。
>
> できたシートの右上に **「新工種：考慮する／考慮しない」** と出るので、
> どちらで作られたか一目で分かります。

（うまく開けないときは、文字だけのページが出るこちらでも構いません）

https://raw.githubusercontent.com/maedaatsushi5908-design/work/claude/intelligent-feynman-5jyidy/infla-slide/vba/ALL_IN_ONE.bas

#### 画面での操作

1つめのリンクを開くと、コードが並んだ**枠**が表示されます。
その枠の**右上**に小さなボタンが並んでいます。

```
                                          ┌────────────────────────┐
                                          │ Raw │ ⧉ │ ↓ │ ✏ │ ⋯ │
                                          └────────────────────────┘
                                            ↑     ↑
                                    文字だけ表示  ここを押すと全部コピー
```

- **`⧉`（四角が2枚重なったアイコン）を押すと、ファイル全体がコピーされます。** これが一番早いです
  （マウスを乗せると "Copy raw file" と出ます）
- `Raw` を押すと文字だけのページに変わるので、`Ctrl + A` → `Ctrl + C` でも同じです

2つめのリンク（`raw.githubusercontent.com` の方）を開いた場合は、
最初から文字だけのページなので `Ctrl + A` → `Ctrl + C` でコピーしてください。

#### Excelに貼り付ける

1. Excelで `Alt + F11` を押してVBE（Visual Basic Editor）を開く
2. メニューの **「挿入」→「標準モジュール」**
3. 右側に白い入力画面が出るので、そこをクリックして `Ctrl + V`
4. `Alt + F11` でExcelに戻る

これで終わりです。**モジュール名の変更は不要**です。

> **参照設定は触らなくて大丈夫です。** ツール→参照設定の追加は要りません。

### 3. マクロを有効にする

ブックを開き直したとき、上部に「セキュリティの警告 マクロが無効にされました」が出たら
**「コンテンツの有効化」** を押してください。

## 毎回の手順

### 手順1　エスティマからCSVを2本出す

`機能 → CSV連携 → 抽出指示ファイル「スライド用csv出力」→ csv抽出`

**単価適用日を変えて2回**出力します。

| | 単価適用日 | ファイル名の例 |
|---|---|---|
| 旧単価CSV | 当初 | `〇〇工事_旧単価.csv` |
| 新単価CSV | スライド基準日 | `〇〇工事_新単価.csv` |

数量・工種構成は同じで、単価だけが違うCSVになります。

### 手順2　設定シートを作る

`Alt + F8` → **`設定シート作成`** → 実行

「設定」シートができるので、**黄色いセル**に入力します。

| 項目 | 入れるもの |
|---|---|
| 工事名 | 工事名 |
| 工事場所 / 工期 | 任意 |
| **請負代金額** | 税込。様式4-2号の請負率の計算に使います |
| **基準日** | インフレスライドの請求日 |
| 発注者 / 受注者 | 任意 |
| 旧単価CSVパス / 新単価CSVパス | 空欄でOK（実行時にダイアログで選べます） |
| 文字コード | 既定は `Shift_JIS`。文字化けしたら `UTF-8` に |
| 使用系列 | `変更`（既定）か `当初`。CSVの**①列＝変更設計、②列＝当初設計**です |
| **新工種を考慮する** | `する`／`しない`。**しない**にすると新工種の列・系列を出さず、受注者負担1%の母数は残工事そのもの（P1''＝P1'）になります |
| **契約保証費** | 当初設計時の額 |

下の方の経費率の係数は、道路改良工事・公園工事等の値が入っています。
**違う工種区分なら、ここを直すか、あとで経費計算シートの率セルを直接上書きしてください。**

### 手順3　マクロを実行する

`Alt + F8` → **`スライド計算表作成`** → 実行

1. 「旧単価のCSVを選択してください」→ 旧単価CSVを選ぶ
2. 「新単価のCSVを選択してください」→ 新単価CSVを選ぶ

2つのシートができます（スライド計算表／スライド調書）。

### 手順3-2　特殊集計区分CSVで処分費・管材費を自動入力する（任意）

エスティマで **特殊集計区分一覧表のCSV** を出せる場合は、
`O列（処分費〇）`・`P列（管材費〇）`・`AA列（処分費額）` を手入力せずに自動で入れられます。

**一覧表はスライド前・スライド後の2本必要です。** 単価適用日を変えて2回出力してください
（スライド用csvを2本出すのと同じやり方です）。

```
Alt+F8 →「特殊集計区分CSV取込」→ 実行
```

1. **【スライド前】**の一覧表CSVを選ぶ → AA列に入ります
2. **【スライド後】**の一覧表CSVを選ぶ → AB列に入ります
   - 後の一覧表が無ければ**キャンセル**。AB列は空のままになり、計算式はAA列の額を使います
3. 「いま入っている〇を消してから入れ直すか」を聞かれます
   - 初回は［はい］。手で直したあとに取り込み直すときも［はい］が安全です
4. `_特殊集計取込結果` シートに、入れた行と入れられなかった行が一覧で出ます

| 集計区分名称 | 入るところ |
|---|---|
| `直工内の処分費等` | O列に `〇`、AA列（前）・AB列（後）に金額 |
| `水道工事における管財費` | P列に `〇` |
| 特殊集計区分外 | 何も入れません |

- 一覧表は **代価表の中の基礎単価**（処分費そのもの）を並べたものなので、
  **F列 `代価表等コード番号` → G列 `親施工単価コード番号` → `基礎単価コード`** の順に
  コードをさがして内訳の行を特定します。
  内訳に無ければ `_単価表` シート（代価表の中身の索引）で**所属する代価表までさかのぼります**。
  同じ内訳の行に当たる行が複数あれば **金額を合算** します
- **`_単価表` シートは［スライド計算表作成］のときに作られます。**
  古いバージョンで作ったブックには入っていないので、取込の前に作り直してください
- **突合できなかった行には、さがしたコードがそのまま出ます。**
  そのコードがスライド計算表のA列に無いということなので、
  まず一覧表とスライド用csvが同じ設計書から出ているかを確かめてください
- **スクラップの行には処分費の〇を付けません**（売却益なので処分費ではありません。㉒で別に扱います）
- **金額の列が空だった行は赤字で出ます。AA列を必ず手入力してください**
  （空のままだとその行の金額を全額 処分費として扱い、過大になります）
- 詳しくは [特殊集計区分CSV.md](特殊集計区分CSV.md) を見てください

> **先に［特殊集計区分CSV構造チェック］を実行すると**、列の並びだけを
> `_特殊集計CSV構造` シートに書き出します（金額・数量・単価は「（数値）」に置き換わります）。
> 取り込めなかったときは、このシートを見れば原因が分かります。

### 手順4　黄色セルを手入力する

#### スライド計算表・明細部

| 列 | 項目 | 入れるもの |
|:---:|---|---|
| **L** | 数量（出来形） | 出来高検査の数量。M列の残工事は自動で `=K-L` |
| **O** | 処分費〇 | 処分費の行に `〇`。**スクラップには付けません**（売却益なので処分費ではありません。㉒で別に扱います）<br>※特殊集計区分CSVがあれば手順3-2で自動で入ります |
| **P** | 管材費〇 | 水道工事の管材費の行に `〇`<br>※特殊集計区分CSVがあれば手順3-2で自動で入ります |
| **Q** | 新工種〇 | **基準日以降に追加された新工種の行に `〇`**。当初数量0・変更数量ありの明細には自動で入ります（設定でオフにできます）。基準日より前の変更なら外してください<br>※「新工種を考慮する」を `しない` にした場合、この列は出ません |

> R列は明細部では使いません。経費計算部のZコード項目の区分だけに使います。

| **AA** | 処分費額（スライド前） | **全数量に対する処分費の総額**を入力。処分費と運搬費の合算額から処分費分だけ。空欄ならその行の金額を全額 処分費として扱います<br>※特殊集計区分CSVがあれば手順3-2で自動で入ります |
| **AB** | 処分費額（スライド後） | 空欄ならAA列の値を使います。処分費は据置が多いのでAA列だけで足ります |

> 金額はすべて **単価×数量を1円未満で切り捨て** て計算します。
>
> 入力した金額は**数量比で出来形・残工事に割り振ります**（割り振った額も1円未満切り捨て）。
> たとえば全数量310に対して 3,000,000 円と入れ、出来形が124なら
> 出来形分 ＝ 3,000,000 × 124 ÷ 310 ＝ 1,200,000 円 です。
> 単価が分からなくても、設計書の処分費の金額をそのまま入れれば足ります。

出来形は**明細行だけ**入れてください。階層行（工種・種別・細別の行）は自動で集計されます。

#### スライド計算表・経費計算部（明細の下）

| 項目 | 入れるもの |
|---|---|
| **Zコード項目の区分（R列）** | **自動で入りますが、違っていたら直してください**（下記） |
| ⑦⑪⑮ 経費率 | 自動計算した値が入っています。**積算システムの値があれば上書き**してください |
| ⑯契約保証費 | 設定シートの値が入ります。違えば直接直してOK |

##### Zコード項目の区分

諸経費部のZコード項目を1行ずつ並べ、R列に区分を入れています。

| 区分 | 意味 | 自動判定 |
|:---:|---|---|
| **積** | 共通仮設費の積上分（運搬費・準備費・技術管理費など）。④に算入 | コードが `Z0001`〜`Z0039` |
| **原** | ⑬工事原価に加算（工期延長等に伴う増加費用など） | コードが `Z0040`〜`Z0044` |
| **価** | ㉑工事価格に加算（設計委託費など） | コードが `Z0045` 以降 |
| **ス** | スクラップ。㉒に算入（**1000円単位に切捨**） | 名称に「スクラップ」を含む |
| 空欄 | 計算に使わない | 支給品費（共通仮設費計から除く運用のため） |

**課の運用と違う場合はR列を直してください。** 全系列（S〜Y列）に一度に効きます。

率を自前で持つのは **S列（前・全体）・V列（後・全体）・X列（新工種抜き・全体）の3つだけ**です。
T列はS列、W列はV列、Y列はX列の率を参照します。
**積算システムで率を取る場合でも3回で済みます。**

#### スライド調書（様式4-2号）

| セル | 項目 |
|---|---|
| **C14** | **請負代金額（税込）。ここだけ手入力**（設定シートの値が初期値で入ります） |

請負率(%)・請負工事価格（税抜）・消費税相当額は、入力した請負代金額から**計算で出ます**。

### 手順5　できあがり

**スライド調書（様式4-2号）の G16 が スライド額 S'** です。
E3に「増額スライド」「減額スライド」の判定が出ます。

調書の金額はすべてスライド計算表からリンクしているので、
**出来形や〇を直すと調書も自動で追従します。**

## 画面の見方

### スライド計算表（1枚に明細と経費計算が入っています）

```
【明細部】8行目〜（Zコードより前がすべて直接工事費）
A     コード（非表示にしてOK）
B〜F  費目／工事区分／工種／種別／細別   ①②③④のマーカーで階層を表現
G,H   施工単価名称／規格
I,J   単価（スライド前／スライド後）     ← 旧単価CSV／新単価CSV
K,L,M 数量（全体／出来形★／残工事）
N     単位
O,P,Q    処分費〇★／管材費〇★／新工種〇☆（当初0・変更ありの行に自動）
R        区分（経費計算部のZコード項目でだけ使う）★
S,T,U    スライド前（全体／出来形／残工事）  ＝ ROUNDDOWN(単価×数量, 0)
V,W      スライド後（全体／残工事）          ＝ ROUNDDOWN(単価×数量, 0)
X,Y      新工種抜き（全体／出来形）      ← 新工種〇の行を0にしたもの
Z        摘要
AA,AB    処分費額（全数量分・前★／後★）
AC〜AI   処分費額（7系列）

【経費計算部】明細のすぐ下
①〜③ → Zコード項目を1行ずつ（R列に区分 積/ス/空欄） → ④〜㉔
を S〜Y の7系列で計算
★＝手入力　☆＝自動（修正可）
```

7系列の意味です。

| 列 | 内容 | 経費率 |
|:---:|---|---|
| S | スライド前・全体（＝元設計） | 自前 |
| T | スライド前・出来形（＝出来高） | S列の率 |
| U | スライド前・残工事 | 素材のみ |
| V | スライド後・全体（＝スライド設計書） | 自前 |
| W | スライド後・残工事（＝単価更新設計書 残工事） | V列の率 |
| X | 新工種抜き・全体 | 自前 |
| Y | 新工種抜き・出来形 | X列の率 |

「新工種を考慮する」を `しない` にすると、**X・Y列は出ません**（S〜Wの5系列になります）。

**様式4-2号が使うのは S・T・W・X・Y の5列**です。

背景色は階層のレベルです。濃い青＝費目、薄い青＝工事区分、以下同様。

### スライド調書（様式4-2号）

```
P1'  = 請負工事価格 − 出来高（請負率考慮）           … 残工事
P1'' = 新工種抜き   − 新工種抜き出来高（請負率考慮）  … 1%の母数
S'   = P2' − P1' − P1'' × 1%      （増額スライド）
     = P2' − P1' + P1'' × 1%      （減額スライド）

※「新工種を考慮する」を `しない` にした場合は **P1'' ＝ P1'** になります。
```

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 文字化けする | 設定シートの「文字コード」を `UTF-8` にして再実行 |
| 「明細を1行も読み取れませんでした」 | CSVが「スライド用csv出力」の形式か確認。列が違う場合は連絡ください |
| 階層がおかしい | `CSV構造チェック` を実行して、その結果（金額は出ません）を送ってください |
| 「旧CSVと新CSVで行がずれていた」と出る | 2本のCSVで工種構成が変わっています。名称・規格・単位で突合し直すので多くは問題ありませんが、メッセージの「旧単価を据え置いた明細」の件数が多いときは要確認 |
| 摘要欄に赤い★が出る | 技術管理費の行が見つからないなど、自動で決められなかった箇所です。その行の式を直してください |
| 仮設材運搬費・技術管理費が積上分に入らない | 経費計算部のZコード項目の行で、R列に `積` と入れてください |
| 共通仮設費が大きすぎる | Z0040以降の計算行に `積` が付いていないか確認。付いていると二重計上になります |
| 直接工事費に仮設工が入っていない | Zコード（`Z00…`）より前の行はすべて直接工事費に入ります。入っていなければ `CSV構造チェック` の結果を送ってください |
| 経費率が課の値と違う | 経費計算部の ⑦⑪⑮ を直接上書きするか、設定シートの係数（A・B・地域補正・週休補正）を変えてください |
| 工事費が金入設計書と合わない | 経費率を積算システムの値で上書きしてみてください。それでも合わなければ ⑯契約保証費・㉒スクラップ・端数整理を確認 |
| 新工種なし版を貼ったのに新工種の列が出る | 古い「設定」シートに項目が無く、既定に戻っていました。`スライド計算表作成` を実行すると設定が追加されるので、確認してもう一度実行してください。シート右上の「新工種：…」で現在のモードが分かります |
| マクロが一覧に出てこない | モジュール名（オブジェクト名）の設定を忘れていないか、貼り付け先が「標準モジュール」か確認 |

## やり直したいとき

`スライド計算表作成` を実行すると、2つのシートは**作り直し**になります。
手入力した出来形や〇は消えるので、やり直す前にシートをコピーして退避してください。

（出来形の入力をやり直さずに済むよう、次は「前回の入力を引き継ぐ」機能を足すこともできます。必要なら連絡ください。）
