# インフレスライド設計書 作成VBA

積算システムから出力したCSVを元に、インフレスライド設計書の体裁を整えるExcel VBAです。

## 現在の状態

| 項目 | 決まっていること |
|---|---|
| CSVの出し方 | 積算システムから**変動前（旧単価）／変動後（新単価）の2本**を出力し、VBAで突合する |
| 発注機関 | **都道府県・政令市** |
| 既存VBAとの関係 | **別の新規VBA**として作る（現行の設計書整形VBAは触らない） |

`vba/` に動く叩き台が入っています。貼り付け方と実行手順は [`vba/README.md`](vba/README.md) を参照してください。
サンプルCSV生成マクロを付けたので、**実データが無くても今すぐ動作確認できます。**

次は `input/` に実物のCSVとテンプレートを置いてもらえれば、様式と列を実物に合わせ込みます。

## 受け渡しの方法（ネットワーク制限対応）

会社PCからファイルのダウンロードができない前提で、以下の運用にします。

### あなた → こちら（GitHubへ渡す）

**ドラッグ＆ドロップは不要です。** 状況に応じて次の3つの方法があります。

#### 方法A：テキストを貼り付けるだけ（CSV・VBA向け／ファイル操作は一切なし）

CSVとVBAはテキストなので、これが一番確実です。

1. リポジトリのページで **Add file → Create new file**
2. ファイル名の欄に `infla-slide/input/sample_変動前.csv` と入力
   （`/` を打つとフォルダが自動で作られます）
3. 本文の枠にCSVの中身をそのまま `Ctrl+V`
4. 下の **Commit changes** を押す

CSVは秀丸やメモ帳で開いて `Ctrl+A` → `Ctrl+C` すれば全部コピーできます。
VBAはVBEでモジュールを開いて `Ctrl+A` → `Ctrl+C` です。

#### 方法B：ファイル選択ダイアログを使う（テンプレの .xlsx 向け）

1. リポジトリのページで **Add file → Upload files**
2. 画面中央の **「choose your files」** というリンクをクリック
   （ここを押すと、ドラッグ＆ドロップではなく**通常のファイル選択ダイアログ**が開きます）
3. ファイルを選んで **Commit changes**

#### 方法C：チャットに直接貼る

GitHubを経由せず、CSVの中身をチャットにそのまま貼り付けてもらっても読めます。
数行〜数十行程度なら、これが一番早いです。

#### テンプレートの .xlsx がどうしても渡せない場合

方法Bも使えないときは、**テンプレの体裁をテキストに変換してから貼り付けてください。**

`vba/M91_TemplateDump.bas` を貼り付けて `テンプレ構造書き出し` を実行すると、
セルの値・結合・罫線・列幅・行高・印刷設定が `_構造書き出し` シートにテキストで出力されます。
そのA列をコピーして、方法Aか方法Cで渡してください。それだけで様式を再現できます。

> コミット先のブランチはどこでも構いません（`main` でも `claude/...` でも拾えます）。

### こちら → あなた（コピペで受け取り）

VBAコードは `infla-slide/vba/` にプレーンテキスト（`.bas`）で置きます。
GitHubのファイル画面右上の **Raw** ボタンを押すとテキストだけの画面になるので、
`Ctrl+A` → `Ctrl+C` でコピーし、ExcelのVBE（`Alt+F11`）で
「挿入 → 標準モジュール」して `Ctrl+V` で貼り付けてください。

コピペ運用に合わせて、コードは以下の方針で書きます。

- **参照設定なしで動く**（すべて遅延バインディング）。VBEでの参照設定追加が不要
- **モジュール単位で完結**。1モジュールずつ貼り付ければ動く
- **外部ファイルのダウンロード不要**。テンプレートのシートもVBAが自前で生成できるようにする
- 貼り付け直後に動くよう、シート名・列位置は**設定シート**で調整できる形にする
