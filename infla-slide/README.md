# インフレスライド設計書 作成VBA

積算システムから出力したCSVを元に、インフレスライド設計書の体裁を整えるExcel VBAです。

## 現在の状態

| 項目 | 決まっていること |
|---|---|
| CSVの出し方 | 積算システムから**変動前（旧単価）／変動後（新単価）の2本**を出力し、VBAで突合する |
| 発注機関 | **都道府県・政令市** |
| 既存VBAとの関係 | **別の新規VBA**として作る（現行の設計書整形VBAは触らない） |

`vba/` に動く叩き台が入っています。貼り付け方と実行手順は [`vba/README.md`](vba/README.md) を参照してください。
サンプルCSV生成マクロを付けたので、**実データが無くても今すぐ動作確認できます。**

次は `input/` に実物のCSVとテンプレートを置いてもらえれば、様式と列を実物に合わせ込みます。

## 受け渡しの方法（ネットワーク制限対応）

会社PCからファイルのダウンロードができない前提で、以下の運用にします。

### あなた → こちら（GitHubへアップロード）

GitHubのWeb画面から `infla-slide/input/` にドラッグ＆ドロップでアップロードできます。
（リポジトリのページ → `infla-slide/input` → `Add file` → `Upload files`）

| 置いてほしいもの | ファイル名の例 | 備考 |
|---|---|---|
| 積算システムのCSVサンプル | `sample_変動前.csv` | 工事名・金額はダミーでOK |
| 同上（変動後があれば） | `sample_変動後.csv` | |
| インフレスライド設計書のテンプレ | `template_インフレスライド.xlsx` | 様式が分かればExcelでもPDFでも可 |
| 現行の設計書整形VBA | `current_設計書整形.bas` | 拡張子 `.bas` か `.txt` で。エディタからコピペで作れます |
| 完成イメージ（手作業で作った過去の設計書） | `sample_完成形.xlsx` | あると精度が上がります |

> `.xlsx` のようなバイナリでも中身は読めます。VBAはExcelファイルに埋め込まれたままだと読めないので、
> VBEで対象モジュールを右クリック →「ファイルのエクスポート」→ `.bas` にするか、
> コード全体をコピーしてテキストファイルに貼り付けてアップロードしてください。

### こちら → あなた（コピペで受け取り）

VBAコードは `infla-slide/vba/` にプレーンテキスト（`.bas`）で置きます。
GitHubのファイル画面右上の **Raw** ボタンを押すとテキストだけの画面になるので、
`Ctrl+A` → `Ctrl+C` でコピーし、ExcelのVBE（`Alt+F11`）で
「挿入 → 標準モジュール」して `Ctrl+V` で貼り付けてください。

コピペ運用に合わせて、コードは以下の方針で書きます。

- **参照設定なしで動く**（すべて遅延バインディング）。VBEでの参照設定追加が不要
- **モジュール単位で完結**。1モジュールずつ貼り付ければ動く
- **外部ファイルのダウンロード不要**。テンプレートのシートもVBAが自前で生成できるようにする
- 貼り付け直後に動くよう、シート名・列位置は**設定シート**で調整できる形にする

## フォルダ構成

```
infla-slide/
├── README.md        このファイル
├── docs/            仕様メモ・計算ルールの整理
├── input/           ← あなたがCSV・テンプレ・現行VBAを置く場所
└── vba/             ← こちらが書くVBA（Rawからコピペ）
```
