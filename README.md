# kenmo氏の新高値ブレイク投資法 バックテスト

## 戦略概要

kenmo氏の著書に基づく **新高値ブレイク投資法** のバックテストシステムです。

### 投資ルール

| ルール | 内容 |
|--------|------|
| **エントリー条件** | 終値がN営業日間（デフォルト: 260日 ≈ 52週）の新高値を更新 |
| **出来高条件** | 前日比で出来高が増加していること |
| **エントリー価格** | シグナル翌日の始値 |
| **損切り** | エントリー価格から -8% 下落した場合 |
| **トレーリングストップ** | 保有中の最高値から -15% 下落した場合 |
| **最大保有銘柄数** | 5銘柄（均等分散）|

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
# デフォルト設定で実行（2015〜2024年、Nikkei225主要30銘柄）
python main.py

# カスタム設定
python main.py \
  --start 2018-01-01 \
  --end 2023-12-31 \
  --capital 3000000 \
  --high-period 130 \
  --stop-loss -0.10 \
  --trailing -0.20 \
  --max-pos 10

# 特定銘柄でテスト
python main.py --tickers 7203.T 6758.T 9984.T

# グラフを画面表示
python main.py --show
```

## オプション

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--start` | 2015-01-01 | バックテスト開始日 |
| `--end` | 2024-12-31 | バックテスト終了日 |
| `--capital` | 1,000,000 | 初期資金（円） |
| `--high-period` | 260 | 新高値判定期間（営業日）|

| `--tickers` | - | 対象ティッカーをスペース区切りで指定 |

## 韓国指数（KOSPI）との連動チェック

「最近は日本株が韓国指数と連動している」という体感を数字で検証するツール。

```bash
# 指数レベルの検証
python korea_correlation.py

# 構造変化の日付で前後比較（例: 韓国レバレッジETF上場日）
python korea_correlation.py --split-date 2026-05-27

# 対象116銘柄それぞれの韓国感応度をランキング
python korea_correlation.py --scan

# バックテストの取引をKOSPIレジームで層別（フィルターになるか）
python korea_correlation.py --trades
```

### 検証する4つの問い

| # | 問い | 手法 |
|---|------|------|
| 1 | 直近の連動は本当に過去より強いのか | ローリング相関・パーセンタイル・Fisher z検定 |
| 2 | それは韓国要因か、単に米国株という共通要因か | 米国株（S&P500・SOX）を統制した**偏相関** |
| 3 | 韓国は日本に**先行**するのか | リードラグ分析（lag −5〜+5） |
| 4 | どの銘柄が韓国に敏感か | 銘柄別の対KOSPI相関・ベータ・日経を除いた偏相関 |

**問い2と3が要点。** 相関が高いだけでは意味がない：

- 日韓がともに米国発の材料に反応しているだけなら、KOSPIを見る意味はない（米国株・SOXを直接見るべき）。偏相関で切り分ける。
- 韓国(KRX)と日本(TSE)はどちらもUTC+9の09:00〜15:30でほぼ同時に立会するので、**同時刻(lag=0)の相関がいくら高くても売買には使えない**。使えるのは lag≧1（前日までの韓国の値動き→翌日の日本株）だけ。

### 主なオプション

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--start` / `--end` | 2015-01-01 / 今日 | 分析期間 |
| `--window` | 60 | ローリング相関の窓（営業日）|
| `--recent` | 60 | 「直近」とみなす営業日数 |
| `--split-date` | - | この日以降を「直近」として過去と比較（`--recent` より優先）|
| `--us-lag` | 1 | 米国指数をずらす日数（1=前夜のセッション）|
| `--scan` / `--trades` | - | 銘柄別スキャン / 取引のレジーム層別 |
| `--no-plot` / `--show` | - | グラフを出力しない / 画面表示 |

### 出力

| ファイル | 内容 |
|---------|------|
| `output/korea_correlation.png` | ローリング相関の推移・リードラグ・直近の散布図 |
| `output/korea_ticker_sensitivity.csv` | 銘柄別の対KOSPI感応度（`--scan` 時）|

### 注意

- **このツールは実データのみを使い、合成データにフォールバックしない。** ランダムウォークの合成データで相関を測っても無意味なため、データが取れない場合はエラーで停止する（`main.py` のバックテストはオフライン時に合成データを使うので挙動が違う）。
- `--us-lag 1` が既定なのは、米国市場が日本・韓国の引け後に動くため。日本のt日に効くのは米国のt−1セッション（前夜）。
- 日次リターンにはボラティリティ・クラスタリングがあるため、p値は実際よりやや有意に出る傾向がある。
- `scipy` があればt分布の正確なp値を使い、無ければ正規近似にフォールバックする（任意依存）。
