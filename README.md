# 新高値ブレイク × 移動平均線フィルター 投資システム

新高値ブレイク投資法に **移動平均線フィルター** を重ねた、日本株の売買システムです。
バックテスト（`main.py`）と、毎朝の売買候補を通知するデイリースキャナー（`scanner.py`）から成ります。

## なぜ移動平均線をフィルターにするのか

新高値ブレイクは「上昇トレンドの初動」を捉える手法ですが、**下降トレンドの途中で起きる
一時的な戻り高値でもシグナルが出てしまう** という弱点があります。

移動平均線を重ねることで、

1. **トレンドが上を向いている銘柄だけを買う**（個別銘柄フィルター）
2. **相場全体が崩れている間は新規で買わない**（地合いフィルター）
3. **トレンドが崩れた時点で撤退する**（MA割れエグジット・任意）

という3段階の絞り込みができます。

## 投資ルール

### エントリー条件（すべて満たしたとき翌日の始値で買い）

| # | ルール | 内容 |
|---|--------|------|
| 1 | **新高値ブレイク** | 終値がN営業日（デフォルト195日 ≈ 39週）の高値を更新 |
| 2 | **出来高** | 前日比で出来高が増加している |
| 3 | **移動平均フィルター** | 下記 a〜c をすべて満たす |
| 4 | **地合いフィルター** | 日経225が200日移動平均より上にある |

移動平均フィルターの内訳:

| 記号 | 条件 | 意味 |
|------|------|------|
| a | 終値 > 25日MA・75日MA・200日MA | 短期〜長期のどの目線でも上昇中 |
| b | 25日MA > 75日MA > 200日MA | パーフェクトオーダー（きれいな上昇の並び） |
| c | 200日MA > 20日前の200日MA | 長期トレンドが上向き（横ばい・下降を除外） |

### エグジット条件（いずれかに触れたら手仕舞い）

| ルール | 内容 | デフォルト |
|--------|------|-----------|
| **損切り** | エントリー価格から -10% | 有効 |
| **トレーリングストップ** | 保有中の最高値から -20% | 有効 |
| **移動平均割れ** | 終値が75日MAを2日連続で下回る | **無効**（`--ma-exit` で有効化） |

> MA割れエグジットは損切り・トレーリングストップより早く反応するため、
> 保有期間が大きく短くなります。既存の売買ルールを変えたくない場合はオフのまま使ってください。

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

### バックテスト

```bash
# デフォルト設定（2015〜2024年、品質フィルター済み116銘柄）
python main.py

# 移動平均線フィルターの効果を段階的に比較する
python main.py --compare

# MA割れエグジットも有効にする
python main.py --ma-exit

# 移動平均の期間を変える（例: 5日/25日/75日）
python main.py --ma-short 5 --ma-mid 25 --ma-long 75

# 移動平均フィルターを外して素の新高値ブレイクと比べる
python main.py --no-ma-filter --no-market-filter
```

`--compare` は次の4パターンを同じデータで走らせて並べます。

```
① ベースライン（新高値ブレイクのみ）
② ＋ MAフィルター（エントリー）
③ ＋ MA割れエグジット
④ ＋ 地合いフィルター（フル）
```

### デイリースキャン

```bash
# 朝のスキャン（MAフィルターを通過した候補だけが並ぶ）
python scanner.py

# Discord などに通知
python scanner.py --notify

# MAフィルターを外して素の新高値ブレイクを見る
python scanner.py --no-ma-filter

# 保有銘柄のMA割れも売り推奨に含める
python scanner.py --ma-exit
```

スキャン結果には地合い（日経225と200日MAの位置関係）が表示され、
地合いが悪化しているときは「新規エントリーは見送り推奨」と警告します。
MAフィルターで弾かれた新高値銘柄も、理由つきで参考表示されます。

### パラメータ最適化

```bash
python optimize.py              # 売買パラメータ（新高値期間・損切り・トレーリング）
python optimize.py --mode ma    # 移動平均線フィルターのパラメータ
```

### テスト

```bash
python test_ma_filter.py
```

移動平均の計算、各フィルター条件、先読み（ルックアヘッド）が無いこと、
バックテストへの反映などを、ネットワーク不要の合成データで検証します。

## 主なオプション

### 共通

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--start` | 2015-01-01 | バックテスト開始日 |
| `--end` | 2024-12-31 | バックテスト終了日 |
| `--capital` | 1,000,000 | 初期資金（円） |
| `--high-period` | 195 | 新高値判定期間（営業日）|
| `--stop-loss` | -0.10 | 損切りライン |
| `--trailing` | -0.20 | トレーリングストップ |
| `--max-pos` | 5 | 最大保有銘柄数 |
| `--tickers` | - | 対象ティッカーをスペース区切りで指定 |
| `--no-cache` | - | データを再取得（キャッシュ無効） |
| `--show` | - | グラフを画面表示 |

### 移動平均線フィルター

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--ma-short` | 25 | 短期移動平均（営業日）|
| `--ma-mid` | 75 | 中期移動平均（営業日）|
| `--ma-long` | 200 | 長期移動平均（営業日）|
| `--ma-slope-days` | 20 | 長期MAの傾きを見る期間 |
| `--no-ma-filter` | - | 移動平均フィルターを無効にする |
| `--no-alignment` | - | パーフェクトオーダー条件を外す |
| `--ma-exit` | 無効 | MA割れエグジットを有効にする |
| `--ma-exit-period` | 75 | MA割れ判定に使う移動平均 |
| `--ma-exit-days` | 2 | 何日連続で割れたら手仕舞うか |
| `--market-ma` | 200 | 地合い判定の移動平均 |
| `--no-market-filter` | - | 地合いフィルターを無効にする |
| `--compare` | - | フィルター有無を比較する（main.py のみ）|

## 出力ファイル

`output/` ディレクトリに以下が生成されます。

| ファイル | 内容 |
|---------|------|
| `equity_curve.png` | 資産推移グラフ（vs 日経225）+ ドローダウン |
| `trade_distribution.png` | 取引リターン分布・保有日数分布 |
| `monthly_returns.png` | 月次リターン ヒートマップ |
| `trade_log.csv` | 全取引の詳細ログ（エグジット理由つき）|

## プロジェクト構成

```
.
├── main.py            # バックテスト実行（--compare でフィルター比較）

├── strategy.py        # シグナル生成・移動平均線フィルター
├── backtest.py        # バックテストエンジン
├── config.py          # 戦略パラメータ・対象銘柄リスト
├── data.py            # 株価データ取得（yfinance、オフライン時は合成データ）
├── synthetic_data.py  # テスト用合成株価データ生成
├── report.py          # レポート・可視化
├── optimize.py        # パラメータ最適化（--mode ma でMA探索）
├── notify.py          # 通知モジュール（LINE / Discord / Slack / メール）
├── test_ma_filter.py  # 移動平均線フィルターの単体テスト
├── requirements.txt
├── cache/             # 取得データキャッシュ（自動生成）
└── output/            # 出力結果（自動生成）
```

## 注意事項

- このバックテストは教育・研究目的です。実際の投資判断の根拠には使用しないでください。
- 過去のパフォーマンスは将来を保証しません。
- 株価データは `yfinance` 経由でYahoo Financeから取得します。取得できない環境では
  合成データ（幾何ブラウン運動）で動作しますが、**合成データにはトレンドの継続性が
  無いため、移動平均フィルターの有効性を評価する用途には使えません**。
  フィルターの効果は必ず実データで検証してください。
