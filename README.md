# kenmo氏の新高値ブレイク投資法 バックテスト

## 戦略概要

kenmo氏の著書に基づく **新高値ブレイク投資法** のバックテストシステムです。

### 投資ルール

| ルール | 内容 |
|--------|------|
| **エントリー条件** | 終値がN営業日間（デフォルト: 260日 ≈ 52週）の新高値を更新 |
| **出来高条件** | 前日比で出来高が増加していること |
| **エントリー価格** | シグナル翌日の始値 |
| **損切り** | エントリー価格から -8% 下落した場合 |
| **トレーリングストップ** | 保有中の最高値から -15% 下落した場合 |
| **最大保有銘柄数** | 5銘柄（均等分散）|

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
# デフォルト設定で実行（2015〜2024年、Nikkei225主要30銘柄）
python main.py

# カスタム設定
python main.py \
  --start 2018-01-01 \
  --end 2023-12-31 \
  --capital 3000000 \
  --high-period 130 \
  --stop-loss -0.10 \
  --trailing -0.20 \
  --max-pos 10

# 特定銘柄でテスト
python main.py --tickers 7203.T 6758.T 9984.T

# グラフを画面表示
python main.py --show
```

## オプション

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--start` | 2015-01-01 | バックテスト開始日 |
| `--end` | 2024-12-31 | バックテスト終了日 |
| `--capital` | 1,000,000 | 初期資金（円） |
| `--high-period` | 260 | 新高値判定期間（営業日）|
| `--stop-loss` | -0.08 | 損切りライン |
| `--trailing` | -0.15 | トレーリングストップ |
| `--max-pos` | 5 | 最大保有銘柄数 |
| `--no-cache` | - | データを再取得（キャッシュ無効） |
| `--show` | - | グラフを画面に表示 |
| `--tickers` | - | 対象ティッカーをスペース区切りで指定 |

## 外部データによる業績サプライズ推定（external_signals.py）

会社が公表する決算情報を使わず、**企業の「周り」で観測できる公開データ**から
業績の上振れ／下振れを推定する実験モジュールです。

企業の売上は必ず外界に痕跡を残します。ドル円が前年同期より円安なら輸出企業の
利益は機械的に上振れ、SOX指数やASMLの受注が回復すれば半導体装置の受注は
数ヶ月遅れて追随し、銅価格が上がれば非鉄のマージンは直接改善します。

```bash
# 現時点の外部環境スコアで全銘柄をランキング（業種ローテーション向け）
python external_signals.py rank

# 銘柄固有の感応度を過去データから推定してランキング（銘柄選択向け）
python external_signals.py rank --mode fitted

# スコアの内訳を確認
python external_signals.py explain --ticker 8035.T --mode fitted

# この手法が実際に効くかを検証（情報係数 IC を測る）
python external_signals.py validate --start 2016-01-01 --end 2024-12-31

# 使用している外部データと業種別カバレッジ
python external_signals.py sources
```

### 使っている外部データ

| 系列 | 効く業種 |
|---|---|
| ドル円 | 輸出企業全般（自動車・電機・精密） |
| SOX指数 / ASML / TSMC / AMAT | 半導体・製造装置 |
| WTI原油 | エネルギー・商社（自動車はコスト要因） |
| 銅・金先物 | 非鉄・鉄鋼・商社 |
| ZIM（コンテナ海運） | 海運 |
| 米10年金利 | 銀行・証券 |
| 日経225 | 市場全体の水準 |

すべて yfinance 経由で取得するため **APIキー不要・無料** です。
この状態で信頼できるスコアが出るのは **49/116銘柄**（半導体・電機・精密・
金融・自動車・資源・海運・商社）です。

### 政府統計（e-Stat）の接続

建設42銘柄・小売13銘柄・機械7銘柄は市況データでは説明できず、本命は
政府統計です。e-Stat の無料APIキーを設定すると自動的に有効になります。

```bash
# 1. https://www.e-stat.go.jp/api/ で登録（無料・即日発行）
# 2. .env に ESTAT_APP_ID=取得したID を記入
# 3. 設定ファイルを生成
python external_signals.py estat-init

# 4. 統計表IDを検索（IDは統計の改定で変わるためコードに埋め込んでいない）
python external_signals.py estat-search --keyword 建設工事受注動態統計調査
python external_signals.py estat-search --keyword 商業動態統計
python external_signals.py estat-search --keyword 機械受注統計

# 5. 出てきたIDを estat_series.json の stats_data_id に記入
# 6. 接続状況を確認
python external_signals.py sources
```

政府統計は調査対象月から1〜2ヶ月遅れて公表されるため、`lag_months` の
分だけインデックスを後ろにずらして「実際に入手できた日」に置き直しています。
これを怠ると重大な先読みバイアスになります。

未接続でもモジュールは正常に動作し、その業種は残りのドライバーで
正規化されたスコアになります（`sources` に △ と表示されます）。

### 2つのモード

| モード | スコアの意味 | 用途 |
|---|---|---|
| `fixed` | 業種共通の重みで合成した外部環境スコア | 業種ローテーション |
| `fitted` | 銘柄ごとの感応度をリッジ回帰で推定した予測リターン | 銘柄選択 |

`fixed` は同一業種の銘柄が全て同じスコアになるため、業種内の銘柄選択には
使えません。同じ輸出企業でも為替感応度は海外売上比率や為替予約の方針で
大きく違うので、銘柄を選び分けるには `fitted` を使ってください。

### 新高値ブレイク戦略への組み込み

外部環境スコアを既存戦略のエントリーフィルターとして使えます。
新高値ブレイクのうち、外部環境が業績上振れ方向に動いている銘柄だけを買います。

```bash
# フィルター無し（従来どおり）
python main.py

# 外部環境スコアがプラスの銘柄のみエントリー
python main.py --external-filter --external-min-score 0.0

# 銘柄固有の感応度を使う（計算に数分かかります）
python main.py --external-filter --external-mode fitted --external-min-score 0.0
```

| オプション | デフォルト | 説明 |
|---|---|---|
| `--external-filter` | 無効 | 業績フィルターを有効にする |
| `--external-mode` | `fixed` | `fixed` = 業種共通の重み / `fitted` = 銘柄固有の感応度 |
| `--external-min-score` | 0.0 | この値を下回る銘柄のシグナルは見送る |

実行すると「外部フィルターで見送ったシグナル: N 件」が表示されるので、
フィルター無しの結果と総リターン・シャープレシオを比較してください。

### 検証

```bash
python test_external_signals.py
```

先読みバイアス（未来のデータを使ってしまうこと）の検証を含みます。
スコア・感応度の推定・スコア時系列・政府統計の公表ラグのそれぞれについて、
`asof` 時点までのデータのみに依存することを、未来データを足しても結果が
変わらないことで機械的に確認しています。

**使う前に必ず `validate` で IC を確認してください。** 平均 IC が 0 から
有意に離れていなければ、この手法にエッジはありません。またこのスコアは
「業績が上振れる方向に外部環境が動いたか」しか測っておらず、株価が既に
それを織り込んでいるかは測っていません。
