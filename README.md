# kenmo氏の新高値ブレイク投資法 バックテスト

## 戦略概要

kenmo氏の著書に基づく **新高値ブレイク投資法** のバックテストシステムです。

### 投資ルール

| ルール | 内容 |
|--------|------|
| **エントリー条件** | 終値がN営業日間（デフォルト: 260日 ≈ 52週）の新高値を更新 |
| **出来高条件** | 前日比で出来高が増加していること |
| **エントリー価格** | シグナル翌日の始値 |
| **損切り** | エントリー価格から -8% 下落した場合 |
| **トレーリングストップ** | 保有中の最高値から -15% 下落した場合 |
| **最大保有銘柄数** | 5銘柄（均等分散）|

## セットアップ

```bash
pip install -r requirements.txt
```

## 実行方法

```bash
# デフォルト設定で実行（2015〜2024年、Nikkei225主要30銘柄）
python main.py

# カスタム設定
python main.py \
  --start 2018-01-01 \
  --end 2023-12-31 \
  --capital 3000000 \
  --high-period 130 \
  --stop-loss -0.10 \
  --trailing -0.20 \
  --max-pos 10

# 特定銘柄でテスト
python main.py --tickers 7203.T 6758.T 9984.T

# グラフを画面表示
python main.py --show
```

## オプション

| オプション | デフォルト | 説明 |
|------------|-----------|------|
| `--start` | 2015-01-01 | バックテスト開始日 |
| `--end` | 2024-12-31 | バックテスト終了日 |
| `--capital` | 1,000,000 | 初期資金（円） |
| `--high-period` | 260 | 新高値判定期間（営業日）|
| `--stop-loss` | -0.08 | 損切りライン |
| `--trailing` | -0.15 | トレーリングストップ |
| `--max-pos` | 5 | 最大保有銘柄数 |
| `--no-cache` | - | データを再取得（キャッシュ無効） |
| `--show` | - | グラフを画面に表示 |
| `--tickers` | - | 対象ティッカーをスペース区切りで指定 |

## 出力ファイル

`output/` ディレクトリに以下が生成されます：

| ファイル | 内容 |
|---------|------|
| `equity_curve.png` | 資産推移グラフ（vs 日経225）+ ドローダウン |
| `trade_distribution.png` | 取引リターン分布・保有日数分布 |
| `monthly_returns.png` | 月次リターン ヒートマップ |
| `trade_log.csv` | 全取引の詳細ログ |

## パフォーマンス指標

- **勝率** / **プロフィットファクター**
- **平均リターン** / **平均利益** / **平均損失**
- **総リターン** / **最大ドローダウン** / **シャープレシオ**
- **平均保有日数** / **エグジット理由別集計**

## 注意事項

- このバックテストは教育・研究目的です。実際の投資判断の根拠には使用しないでください。
- 過去のパフォーマンスは将来を保証しません。
- 株価データは `yfinance` 経由でYahoo Financeから取得します。
